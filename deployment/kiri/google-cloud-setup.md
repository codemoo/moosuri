# Google setup: historical Cloud Shell entry

The Cloud Shell wizard is retired. Cloud Shell is not required by the member
connection flow. Follow the [current Google connection guide](google.md).

Google requires initial OAuth client registration in its official console;
an installed web client can then be reused for individual member consent.
[Google's registration requirement](https://developers.google.com/identity/protocols/oauth2/resources/best-practices#manual-client-creation).
