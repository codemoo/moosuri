# 이미지 첨부와 보관함

대화 입력의 **이미지 첨부**에서 PNG·JPEG·WebP를 선택한다. 파일마다 준비·업로드·
취소·재시도가 따로 동작한다. 업로드 중에도 글을 작성하고 전송할 수 있으며,
전송 시 준비된 최대 4장만 그 메시지에 고정한다. 아직 업로드 중인 선택은 남는다.
재시도는 원래 메시지와 이미지 조합을 사용한다.

선택한 이미지와 대화 말풍선에 실제 미리보기를 표시한다. **내 이미지 보관함**에서는
미리보기·확대·다운로드·다시 선택·삭제를 제공한다. 목록이 열린 동안 새로 올린
이미지는 새로고침으로 확인한다. 모바일에서는 대화 기록과 입력 영역이 각각
스크롤된다. 보관함과 첨부를 펼쳐 입력창이 아래로 내려가면 입력 영역을 스크롤한다.

이미지를 읽을 모델은 관리자가 `/admin/providers`에서 해당 model/effort의
**이미지 연결 확인**을 완료해야 한다. 실제 합성 색상 이미지를 읽는지 검사하며,
모델 이름이나 목록 표시만으로 이미지 지원을 가정하지 않는다. 연결 설정이 바뀌면
다시 확인한다. 미지원 모델에서는 질문과 이미지 선택을 유지하고 설정 안내를 표시한다.

이미지가 연결된 대화 문맥에서는 이미지 분석과 답변만 지원한다. 도구 실행과
메모리·문서·목표 변경은 아직 연결하지 않았다. 이전 이미지 유래 답변을 포함한
같은 대화에도 이 제한을 적용한다. UTF-8 파일과 제한된 PDF 텍스트 처리는 [개인 파일](private-files.md)을 따른다.
녹음과 제한된 음성 인식은 아래 경로를 따른다. 동영상·PWA 공유받기는 후속 기능이다.

브라우저는 원본을 최대 32MiB·48MP까지 받고, 긴 변 2400px·2MiB 이하로 준비한다.
서버는 실제 포맷과 픽셀을 다시 검사하고 메타데이터 없는 JPEG·작은 미리보기로
저장한다. 계정당 64MiB로 제한하며 다른 계정은 읽을 수 없다. 인증된 이미지 응답은
`no-store`이고 서비스 워커나 공개 정적 캐시에 넣지 않는다. 세션 종료·계정 전환·
삭제 시 화면의 임시 URL도 정리한다.

**삭제하면 이미지와 그 이미지에 의존하는 대화 답변이 함께 철회된다.** 진행 중인
다운로드·업로드·모델 응답도 뒤늦게 살아나지 않게 처리한다. 이미 사용자가 별도로
저장한 다운로드나 과거 암호화 백업까지 지우는 기능은 아니다.

현재 이미지와 미리보기는 SQLite 안에 저장한다. [봉인된 현재 스냅샷 복원](restore.md)은
완료된 이미지와 삭제 기록을 보존하고, 처리 중이던 업로드와 모델 연결 확인은
다시 진행하도록 격리한다. 외부 파일 저장소나 과거 백업의 임의 복원은 지원하지 않는다.

구현 범위와 합성 검증은 [이미지 검증 기록](reviews/2026-11-13-private-images.md)에 있다.

## 녹음해서 글로 입력하기

**음성으로 입력 → 녹음 시작**에서 브라우저 마이크 권한을 요청한다. 녹음 중 입력 크기와 시간이 보이고 **잠시 멈춤/계속 녹음**, **녹음 끝내기**, 미리 듣기·다시 녹음·삭제를 제공한다. 잠시 멈춤은 마이크 track을 유지한다. 화면 전환·기기 interruption·권한/계정 종료는 녹음을 마무리하거나 취소하고 track을 정리한다. 돌아와도 자동으로 다시 녹음하지 않는다. 실제 통화 interruption은 실기기 확인이 별도로 필요하다.

**글로 바꾸기**를 눌러야 녹음을 설정된 OpenAI API로 전송한다. 채팅 모델이나 ChatGPT 구독 연결은 음성 연결을 대신하지 않는다. 관리자가 모델 설정의 **음성을 글로**에서 별도 API 연결/실제 문장 인식을 확인해야 한다. 처리 중에도 글을 쓰고 보낼 수 있다. 완료된 글을 먼저 고치고 **초안에 넣기**로 녹음을 시작한 대화에 한 번 덧붙인다. 최종 **메시지 전송**은 사용자가 따로 누른다. 나중에 쓴 글을 덮어쓰거나 결과를 자동 전송하지 않는다. 삽입이 끝나면 녹음 패널과 임시 미리 듣기를 정리하고 현재 대화의 입력창으로 돌아온다.

녹음은 최대2분, 브라우저 원본8MiB, pause 포함5분이다. 브라우저가 실제 지원하는 녹음 형식으로 미리 듣고, 지원 decoder로16kHz/mono/PCM16 WAV로 준비한다. 녹음 형식/읽기가 불가능하면 이유를 표시하고 원본 preview를 유지하며 다른 브라우저·재녹음을 안내한다. 확장자만 바꾸거나 미지원 codec을 처리 완료로 표시하지 않는다. 서버는 정확한 WAV 길이/채널/샘플레이트/샘플 수를 검사한다. 일반 오디오 파일 업로드·실시간 STT·화자 구분·local STT engine은 포함하지 않는다.

현재 한 계정1건·전체2건, 계정당 하루600초·설치 전체3600초의 독립 음성 한도가 있다. 날짜는 UTC, 최소1초를 예약한다. 제공업체 처리 결과를 확인하지 못하면 사용량이 발생할 수 있다고 안내하며 같은 UUID를 자동 재발송하지 않는다. 응답이 끊기면 **결과 확인**으로 원래 작업을 조회한다. 영수증이 없을 때도 같은 UUID와 준비된 녹음으로만 재접수하며 새 비용의 작업을 자동으로 만들지 않는다. 원래 결과가 불명이면 그 작업을 닫아 표시한다. 사용자가 새로 녹음한 작업은 추가 사용량이 발생할 수 있다. 채팅 token 사용량으로 음성 사용량을 꾸며 표시하지 않는다.

오디오 원본은 서버 task 메모리에만 있고 보관함/브라우저 저장소/서비스 워커에 보관하지 않는다. 준비 전 원본은 현재 화면에서만 들을 수 있으며 새로고침 뒤 복구하지 않는다. 서버의 임시 글은 접수120초 이내의 세션 전용 job으로만 조회하고 삭제·만료·재시작/복원 때 지운다. 만료 청소는 접근/진행 중 검사 시 이루어지며 SQLite 물리 페이지의 즉시 소거를 보장하지 않는다. 이미 만들어진 암호화 백업의 임시 글은 별도 보존 범위이고 복원에서 먼저 철회한다. 사용자가 넣은 글은 기존 정확한 세션의 채팅 초안 복구를 따른다.

[음성 입력 변경](../openspec/changes/add-bounded-voice-input/proposal.md)은 개인 ChatGPT schema32 이후33으로 통합해 독립 검토·Native/Linux·실제 Chrome 검사를 통과했다. [검증 기록](reviews/2026-11-14-bounded-voice-input.md)의 합성 HTTP/브라우저 검사는 실제 provider 음질·한국어 정확도·iOS/Android microphone 검증을 대신하지 않는다.

같은 작업 UUID가 오래 뒤 새 비용으로 재실행되지 않도록 글/오디오 없는 최소 영수증을 계정당 최대4096개 보존한다. 이 한도는 이미지/파일 보관량과 별도이며 아직 일반 영수증 GC를 제공하지 않는다.

음성 연결 끄기·재설정은 영구 authority 세대를 올리고 이전 처리/완료 job의 글을 같은 DB 작업에서 지운다. 나중에 같은 API 연결을 다시 확인해도 이전 글이 되살아나지 않는다. 설정 확인 중 이전 응답이 늦게 도착해도 새 설정이나 꺼진 상태를 덮어쓰지 못한다. 이 동작과 같은 작업의 연결 오류 복구는 독립 재검토와 통합 합성 검증을 통과했다. 실제 기기/provider 수락은 별도다.
