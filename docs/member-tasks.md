# 회원 공간에서 업무 맡기기

**맡긴 일**에서 일반 대화의 답변, 브라우저 업무, 대화에서 요청한 Gmail 조회, 직접 맡긴 자료 조사를 날짜별로 확인한다. 오늘이나 어제를 눌러 해당 날짜를 접고 펼 수 있다. 자료 조사 행에는 **대화에서 실행**, **직접 실행**, **예약 실행** 중 하나가 표시된다. 같은 이름의 예약도 회차마다 별도로 열린다.

업무를 열어 **진행 기록**에서 단계를 선택하면 요청, 읽은 근거 또는 처리 결과가 열린다. 대화에서 맡긴 일은 **원래 대화 열기**로 해당 턴에 돌아간다. 예약 회차에는 예정 시각과 실제 시작 시각이 함께 남는다.

## 한 대화에서 여러 업무 맡기기

“지난 출장 대화에서 정해진 일정을 찾아주고, 내 기억에서 준비물도 찾아줘”라고 보내면 메시지 아래에 출장 일정과 준비물 카드가 생긴다. **여러 검색 한꺼번에 맡기기**에서 찾을 곳과 검색어를 직접 입력할 수도 있다. 한 요청에 최대 6개를 맡긴다. 접수된 조사는 창을 닫아도 회원 타이머가 실행한다.

- “준비물은 전자기기만”이라고 하면 준비물 업무에 조건이 추가된다. 카드의 **진행 기록**에서 조건 변경 전후의 실행과 근거를 각각 연다. **맡긴 일**에서는 같은 업무 행에 회차가 쌓인다.
- “둘 다 어디까지 됐어?”라고 하면 현재 상태를 보여준다. “그거 멈춰”에 해당하는 업무가 여럿이면 멈출 대상을 고른다. 검색어를 비워 둔 업무는 **답변 필요**로 남고 다른 업무는 계속된다. 해당 카드에서 **검색어 입력**을 누르거나 대화에 “질문 답은 일정”이라고 입력하면 같은 업무가 이어진다.
- **보고서 만들기**는 해당 회차에 문서 번호를 발급한다. 조건을 바꾼 뒤에도 **맡긴 일 → 실행 기록**에서 이전 회차를 열어 저장한 보고서를 읽을 수 있다. 다시 열 때 회원이 현재 읽을 수 있는 근거를 확인하므로 원본을 지우거나 수정하면 이전 발췌가 사라진다. 결과가 있는 카드는 **새 검색어로 다시**를 제공한다. 새 업무는 같은 자료 범위에서 새 검색어로 직접 읽는다.
- 브라우저가 같은 내용을 다시 읽어 더 진행할 수 없으면 워크로그에 중단 이유를 남긴다. 회원은 원래 대화에서 지시를 추가하거나 페이지를 직접 조작한 뒤 이어갈 수 있다.

“지난 출장 시간과 챙길 것을 한 장으로 저장해 줘”처럼 결과를 함께 말해도 된다. 묶음 보고서에서 두 자료의 근거를 열고, 같은 대화에서 “방금 찾은 표식은?”이라고 이어 묻는다. 날짜가 여럿이면 어느 출장인지 선택한다. “다음부터” 지정한 선호는 기억으로 관리하고, “이번만” 지정한 조건은 해당 업무에 적용한다.

## 메일, 일정, 구매와 신청

- 메일 원문에 답장을 부탁하면 현재 연결에서 읽은 편지를 선택하고 받을 사람과 본문을 확인한다. Gmail 초안 저장과 발송은 각각의 공급자 접수 번호를 남긴다. 승인 중 최종본을 바꾸면 다시 확인한다.
- 시각과 제목을 들려주면 개인 일정의 변경 내용을 먼저 보여준다. 제목이 같은 일정은 날짜를 골라 옮긴다. 그 사이 달력에서 바뀐 일정은 충돌을 표시한다.
- 상품의 가격·배송 기한이나 공고·지원서 초안을 부탁하면 대화 아래에 비교 결과가 생긴다. 공개 주소를 함께 주거나, 공개 검색어를 직접 지정해 시작한다. 실제 판매처·공고 원문에서 확인한 값과 미확인 조건이 각각 표시된다. 결제·제출에 본인 입력이 필요하면 같은 브라우저를 넘겨받는다.
- “매일 아침 8시에 오늘 일정과 중요한 메일을 알려줘”라고 하면 시간대와 사용할 연결을 보여준다. 필요한 연결을 마치고 반복 조회를 허용하면 예정된 시각에 읽는다. 중요한 메일은 받은편지함에서 Gmail의 중요 표시가 붙은 메일이다.
- “https://status.example.test/service 를 매시간 확인하고 바뀔 때만 알려줘”처럼 공개 주소를 지정하면 첫 관측을 기준으로 삼는다. “이 주소가 바뀌면 알려줘”처럼 간격을 생략하면 매시간 확인한다. 기본 기간은 7일이며 두 값 모두 대화에 표시된다. 감시 기록에서 회차와 변화를 확인하고 **멈추기**로 종료한다.

## 자료 조사

대화에 `기억에서 수첩 찾아줘` 또는 `대화 검색: 준비물`을 입력한다. **맡긴 일 → 자료 조사 맡기기**에서도 찾을 곳, 검색어, 업무 이름을 지정해 **지금 한 번** 실행할 수 있다.

기억 조사는 현재 유효한 기억을 검색한다. 대화 조사는 최근 종료된 텍스트 대화 500턴에서 질문과 답변을 찾는다. 업무 하나가 근거를 최대 8건 읽고, 목록에는 첫 발췌, 상세 결과에는 최대 3건의 발췌를 표시한다. 조회 한도에 도달하면 결과에 표시한다. 근거가 수정되거나 삭제된 뒤 목록이나 상세를 다시 불러오면 그 본문은 사라지고 실행 당시 확인한 건수는 남는다.

## 예약 작업

1. **자료 조사 맡기기**에서 찾을 곳과 검색어를 입력한다.
2. **실행 주기**에서 30분, 1시간, 24시간, 7일 중 하나를 선택한다. 첫 실행은 기기의 현지 시각으로 지정할 수 있다. 비워 두면 선택한 주기 뒤에 시작한다.
3. **예약 추가**를 누른다. 예약 이름을 열면 다음 실행 시각과 **지금 실행**, **일시정지**, **예약 해제**가 보인다. 해제 후에도 실행 기록을 다시 열 수 있다.

예약을 펼쳐 **실행 기록 보기**를 누르면 그 예약에서 직접 실행한 회차와 자동 실행한 회차를 날짜순으로 볼 수 있다. 같은 이름의 예약을 다시 만들면 새 기록에서 시작한다. 예전 회차를 열고 **같은 예약의 실행 기록**을 누르면 해제한 예약의 이력도 찾을 수 있다. 회차를 열면 당시의 요청과 단계별 결과가 보인다.

게이트웨이와 회원 서비스가 실행 중이면 로그아웃한 동안에도 예약이 동작한다. 서비스가 중단된 사이 여러 회차를 놓치면 가장 최근 시각에 해당하는 한 회차를 실행하고 원래 주기를 이어간다. 재개를 누르면 그 시각부터 다시 주기를 센다. 회원 권한이나 설치 경로 세대가 바뀐 뒤에는 기존 권한을 재사용하지 않는다. Gmail 결과는 원래 대화의 연결 권한으로 열고, 업무 목록에는 조회 단계만 표시한다.
