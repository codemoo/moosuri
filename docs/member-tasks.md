# 회원 공간에서 업무 맡기기

**맡긴 일**에서 일반 대화의 답변, 브라우저 업무, 대화에서 요청한 Gmail 조회, 직접 맡긴 자료 조사를 날짜별로 확인한다. 업무를 열어 **진행 기록**에서 단계를 선택하면 요청, 읽은 근거 또는 처리 결과가 열린다. **원래 대화 열기**로 관련 대화에 돌아간다.

## 자료 조사

대화에 `기억에서 수첩 찾아줘` 또는 `대화 검색: 준비물`을 입력한다. **맡긴 일 → 자료 조사 맡기기**에서도 찾을 곳, 검색어, 업무 이름을 지정해 **지금 한 번** 실행할 수 있다.

기억 조사는 현재 유효한 기억을 검색한다. 대화 조사는 최근 종료된 텍스트 대화 500턴에서 질문과 답변을 찾는다. 업무 하나가 근거를 최대 8건 읽고, 결과에 최대 3건의 발췌를 표시한다. 조회 한도에 도달하면 결과에 표시한다. 근거가 수정되거나 삭제되면 다시 연 업무에서도 해당 본문이 사라진다.

## 예약 작업

1. **자료 조사 맡기기**에서 찾을 곳과 검색어를 입력한다.
2. **실행 주기**에서 30분, 1시간, 24시간, 7일 중 하나를 선택한다. 첫 실행은 기기의 현지 시각으로 지정할 수 있다. 비워 두면 선택한 주기 뒤에 시작한다.
3. **예약 추가**를 누른다. 예약 이름을 열면 다음 실행 시각과 **지금 실행**, **일시정지**, **예약 해제**가 보인다. 해제 후에도 실행 기록을 다시 열 수 있다.

게이트웨이와 회원 서비스가 실행 중이면 로그아웃한 동안에도 예약이 동작한다. 서비스가 중단된 사이 여러 회차를 놓치면 가장 최근 시각에 해당하는 한 회차를 실행하고 원래 주기를 이어간다. 재개를 누르면 그 시각부터 다시 주기를 센다. 회원 권한이나 설치 경로 세대가 바뀐 뒤에는 기존 권한을 재사용하지 않는다. Gmail 결과는 원래 대화의 연결 권한으로 열고, 업무 목록에는 조회 단계만 표시한다.
