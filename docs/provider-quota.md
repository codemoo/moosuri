# Provider capacity metadata

Provider capacity is distinct from local `/api/v1/usage` tokens. Quota responses never identify key-wide limits as one model's capacity or the current member's personal use.

- `GET /api/v1/settings/chatgpt/{id}/quota?revision=N` authenticates the owner and exact revision. The [official SIWC inference interface](https://developers.openai.com/siwc/token-sharing-open-source/models-and-inference) documents model discovery/inference and usage-limit failures, but no quota-read endpoint. This route returns `unsupported`, empty metrics, and explicit unknown remaining/reset values. It does not obtain an OAuth access token or call a provider. No ChatGPT `backend-api` endpoints, unrelated scopes, or token guesses are used.
- `GET /api/v1/admin/providers/{id}/quota?revision=N` requires administrator authority before exposing any shared provider metadata. For OpenRouter it reads the [official key endpoint](https://openrouter.ai/docs/api_reference/limits), `GET https://openrouter.ai/api/v1/key`, with the exact current binding. It validates authority/revision during and after retrieval. No ordinary member or other tenant can read key spend/limits through this route. Shared OpenAI/Anthropic/compatible providers explicitly return unsupported/unknown instead of spending an inference request to fabricate a quota snapshot.

`ProviderQuota` in core is the public response contract. Status `known` means allowlisted provider metadata was freshly obtained; individual null fields remain unknown. `unavailable` means the connection cannot currently return verified metadata; stale or guessed values are never substituted. All timestamps are Unix seconds. `reset_at` is populated only from a provider's explicit timestamp; `reset_interval` does not imply a known next reset.

OpenRouter metrics distinguish key credit cap, all-time/current UTC-window spend, enforced budget scopes, and free-model request allowance. Key `usage` is all-time and is not presented as spend against a recurring credit cap. A null key cap does not establish an account balance. Budget remaining may be negative, per the provider contract. Labels and IDs are locally controlled; response key labels, arbitrary diagnostics and guardrail IDs are not exposed. Redirects/proxies/retries are disabled, DNS is validated and pinned, and retrieval is limited to 15 seconds/128 KiB with no inference call.

Sources checked 2026-11-18: [SIWC preview limits](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations), [SIWC models and inference](https://developers.openai.com/siwc/token-sharing-open-source/models-and-inference), [OpenRouter limits](https://openrouter.ai/docs/api_reference/limits). Synthetic parser/authority tests establish implementation behavior; no live provider credential was used to validate quota responses.

Personal Claude settings read the official structured `/usage` report in the owner's existing Linux environment, without sending a billable prompt. Available rows show the provider's scope, remaining percentage and reported reset in the viewer's timezone. If the CLI omits plan limits, settings link to the official usage page. This can occur even with a working text subscription.
