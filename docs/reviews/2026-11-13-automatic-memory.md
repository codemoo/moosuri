# Opted-in source memory extraction — 2026-11-13

Schema14 adds collection-owned extraction grants, bounded jobs/accounting and
source-backed memory origins after backup13. Extraction starts disabled. Enabling
a collection processes later revisions; a particular existing source has an explicit
request action. Reported speaker labels are retained without inferring account
ownership. Model output selects complete paragraph indexes; Store constructs the
actual text, source revision and byte-span evidence.

The grant survives logout without inventing a session. Account/provider/policy or
source changes fence work; dispatch reserves calls, serialized input bytes and
output tokens durably. Unknown dispatched work is not retried automatically.
Source withdrawal prevents late commit, and exact quote suppressions are checked
before prompts and writes. Manual corrections are not silently overwritten. These
are bounded execution guarantees, not proof of semantic fact selection accuracy.
