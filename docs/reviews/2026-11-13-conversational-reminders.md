# Conversational fixed reminders — implementation and integrated acceptance

This bounded unit adds direct current-user Korean/English reminder capture and
weekly ISO weekday rules. The final section records independent review and
integrated schema22 acceptance. Initial standalone evidence is retained below and
is not a live-provider quality or whole scheduled-agent roadmap score. All
accounts/data/providers were synthetic; no production deployment or CI was used.

## Behavior and authority

Store admission inspects only the current authenticated user message. It shares
existing schedule mutations and atomically commits the effect, versioned structured
receipt, final confirmation and completed chat. Accepted commands are never
claimed by the model runner. Existing verified model-choice admission remains a
known entry-point dependency. No semantic classifier or scheduling model tool was
added. Unsupported research/search/send missions get a fixed honest limitation.

UUID plus exact text/timezone/selected target digest handles lost acknowledgements
and actual reopen. Changed payloads conflict. Selected IDs come from persisted
owned receipts and use revision checks; otherwise only literal owned titles or
bounded unique generic controls resolve. Ambiguous time/targets clarify. There is
no stateful clarification continuation. Translation/quote/negative and ordinary
information requests cannot directly mutate schedules through this grammar.
The parser is deliberately bounded and is not claimed as general language intent
coverage. Model/output/retrieval/skill/mail text does not call admission.

Weekly recurrence uses the existing IANA engine: absent local slots produce skips,
repeated slots choose earliest UTC, long downtime delivers one latest valid slot
and summarizes older selected dates. Week counting is bounded rather than a
backlog scan. Existing pause/edit/epoch/quarantine and claimed-lease fences remain
shared with UI-created schedules; no fake background login session is created.

## Integrated schema22 acceptance

The final source applies migration0022 atomically after recovery19/20 and media21.
Request digests retain previous framing when no schedule context is supplied and
bind exact media/timezone/target when supplied. Replay precedes revision checks.
Attached and inherited image context cannot grant a reminder mutation. Sealed-current
restore preserves historical chat receipts while pausing all schedules.

Independent review found and verified repairs for conditional control authority,
misclassifying scheduled research as a fixed reminder, dropping literal reminder
bodies containing summarize/translate words, and Korean ISO-date capture. A later
actual-browser defect left the selected reminder revision stale after pause. The
UI now follows only a matching committed receipt, preserves a newer selection and
keeps uncertain retry payloads unchanged. Separate review exercised SSE-first,
lost-ACK, reject/retry, revoke and newer-selection ordering.
