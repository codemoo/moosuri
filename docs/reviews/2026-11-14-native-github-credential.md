vault-archive unlock/selection path. It reads one exact GitHub repository's numeric/
boolean metadata, with automatic compatible local-grant reuse and durable personal
waiting/status. Tokens/master passwords never become assistant/model/tool fields.
Default server routes remain disabled. Google, broad chat-tool waiting integration,
live-vault rotation subscription and signed native distribution remain open.

Independent integration/security review and Linux acceptance remain root gates.
No native HTTPS assistant enrollment or real-user terminal/password acceptance was
performed. The private native terminal is the unlock/selection surface; no signed
installer or malicious-OS defense is claimed. Archive copies do not automatically
observe later live-vault rotation. Supported local-lock/cancellation can abandon an
in-progress read conservatively as unknown rather than redrive it. Ordinary user
new requests and compatible scope reuse are distinct from retrying an old entry.

Independent review found and the author repaired a P2 stale-clock boundary: the
production transport no longer accepts/reuses a poll timestamp across awaits.
Each authentication signature samples trusted native time after its challenge;
each preparation samples fresh time, and Engine samples again immediately before
journaled adapter entry. A valid signed writer commitment is held past expiry in
the actual workflow regression; subsequent native entry performs zero additional
HTTP requests and settles positively not-dispatched. The affected workflow1/1 and
