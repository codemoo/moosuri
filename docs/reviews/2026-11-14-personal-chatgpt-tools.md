# Personal ChatGPT foreground tools

2026-11-14. Bounded synthetic development-preview acceptance. No actual subscription
account, operational installation, production deployment or CI activation was used.

## Behavior and boundaries

An ordinary member can verify tools for an exact owned ChatGPT binding revision,
model and effort after text verification. The two-round fixed-namespace probe supplies
an unseen random tool result and requires it in the final answer. Catalog presence or
text success does not grant tools. Schema36 defaults older rows to disabled, preserves
proof during text rechecking and never upgrades previously admitted text runs.

Personal foreground runs use the existing bounded tool loop, typed Store operations
and durable private continuation. Every model round resolves current owner authority
and token readiness before dispatch; an uncertain inference is never automatically
replayed. Saved source/memory/skill/artifact reads, exact arithmetic, Calendar reads,
Gmail reads/local drafts and configured web/browser operations retain their current
contracts. Every mail send still needs the user's final explicit preview approval.
This unit does not enable personal memory/artifact/Calendar mutations, media or
background delegation. Restoration clears personal proof and credentials.

executes saved source/calculation; it does not execute every connected tool family.
