# Personal ChatGPT memory and record changes

2026-11-14. Bounded synthetic development-preview acceptance. No live subscription,
production installation, deployment or CI activation was used.

## Accepted behavior

Personal foreground chat with exact text/tool proof now reaches the existing typed
memory and record planners. A direct current-user request can remember, correct or
forget a fact, create a source-grounded document/goal/followup, or edit a pinned record
using its unique literal anchor. Store identity, target revision, provenance, journal
and receipt checks remain authoritative; this adds no generic write tool or approval.

Each private classifier/target selector obtains current personal token readiness
before durable model-step admission and uses the plan-specific encoder. Its private
commentary and decision capsule never become visible answer text or normal answering
history. Successful local writes finish from real Store confirmations, without a
second model-generated success claim. A previously sealed memory command resumes
before new client creation or classification, using its original identity.

Both shared and personal record-writing stages now offer saved source/memory/skill/
calculation/record tools only. Live mail/web/browser/Calendar definitions are omitted;
the existing decoder rejects undeclared calls, and Store still rejects unsupported
external-history provenance. Omission is not a claim that all network activity is
disabled or previous external evidence has disappeared.

Personal Calendar mutations, background missions/delegation and media remain separate.
Mail continues to require explicit approval of its final frozen preview.

## Limits

These cases use synthetic replies and `effort=None`; they do not establish real-model
intent/target-selection accuracy or arbitrary model/effort compatibility. Race coverage
is representative, not an exhaustive cross-product. No dedicated new case stops the
runtime while a dispatched token renewal is held; reviewed ordering records renewal
outcome before honoring stop, with no concrete defect found. Root did not repeat the
entire unchanged Store/protocol suites after this agent-only change.

The inherited16-definition combined-read limit is a separately reviewed repair and
is not fixed by this unit. Real account/provider, physical device and overall assistant
quality acceptance remain separate from these execution-contract checks.
