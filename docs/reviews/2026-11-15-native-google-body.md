# Trusted-native selected Gmail body acceptance

The source adds a separately granted bounded plaintext read selected from a genuine
native INBOX preview. Credential refresh, actual scope/account checks and hidden
Gmail message IDs remain on the trusted device. Only the selected bounded body is
projected to the assistant receipt and owner UI. It is deliberately outside later
model context, conversation recall, artifacts and learned proofs. This is not
zero-knowledge mail storage and does not grant mail sends.

Independent review verified all25 frozen source hashes and accepted old/new signed
bytes, local grant/selector identity, original expiry, Store authorization, fixed
provider paths, MIME bounds and late-result handling. Root additionally cleared
retained UI state at account/run/session closure, fenced asynchronous callbacks
and stale status responses, and reduced default technical UI text. A second
independent review accepted that two-file UI delta and the held-account-response
regression. No native protocol behavior changed in that repair.

Root Linux execution passed the nine native Google tests, including actual local
provider requests, MIME/content/credential-echo rejection, old signature goldens
and encrypted credential/selector restart without replay. Eight broker Store
authority/body/restore outcomes passed initially. An older schema36 fixture still
contained the schema53 browser columns; removing those columns in that predecessor
fixture made its original rollback/retry outcome pass. Production migration SQL
was not changed. Six actual credential Runtime outcomes also passed.

The feature-enabled HTTP boundary then passed all four Google/GitHub cases,
including genuine body selection and arbitrary-identity denial; the default-off
HTTP case passed separately. An initial selector for that enabled suite matched
zero tests and was not counted as evidence. The existing UUID package was promoted
from the server's dev dependencies to normal dependencies for its request DTO; no

reviewed native MIME and Store selection predicates.

React focused credentials/body tests and production TypeScript/Vite build passed.

(scroll-position assertion and an old visible library label); those are not marked

quota behavior, native installed-device operation and physical mobile acceptance
