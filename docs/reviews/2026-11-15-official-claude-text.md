probe, personal model selection and durable saved chat. Rust executes an unchanged
optional official CLI through a pinned rootless Linux profile. It never converts
subscription session tokens into a Rust HTTP adapter. Schema50 follows recovery
allowance schema49. Product behavior and setup are in [Claude execution](../claude-execution.md).
