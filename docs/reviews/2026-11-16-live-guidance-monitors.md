## Delivered behavior

- Additional text instructions receive a durable acknowledgment without a model
  call, then enter the same supported read-only run/mission at a safe processing
  boundary. Actual reads/tool receipts, original budget and deadline are retained.
  Received, applied and closed states are distinct; invalid or refused replies
  cannot claim application. Uncertain transport recovers the exact request ID.
- The chat composer separates current-task instructions from a later-message draft.
  Attachments remain selected until the owner chooses how to retain them. Status
  stays in its original chat turn; an empty completed composer returns to normal.
- Achieved one-off tasks with actual current source receipts can offer follow-up.
  The owner accepts read/check/notify scope, cadence, expiry and optional reuse.
  Exact-account/epoch/scope/template reuse coalesces a matching later task; ordinary
  source changes do not require repeated permission. Mail still needs final-preview
  approval. No policy grants arbitrary browsing, mail sends or wider discovery.
- The scheduler checks local metadata before inference. Unchanged, unrelated and
  provider-version-only changes create no child/model call. A relevant change reads
  at most4 changed documents of4096 bytes each; thread membership is bounded to32.
  Failure/unknown does not retry the same observation. Coverage limits are explicit.
- Stop, expiry, connection/config/epoch changes and source/parent withdrawal fence
  execution and already-published notification list/detail/Push delivery/display.
  Observation review can preserve a local correction without making global memory.
- Korean ordinary nouns such as 기분에/성분에 and ordinary 수업 시간에 no longer
  trigger the interval planner; quantified periods remain routed for interpretation.

## Defects exposed and corrected

The live monitor's stop returned409 once a notification had been published.
`source_suppressed` is immutable creation-time provenance in schema39; attempting
to overwrite it rolled back the entire stop. Stop now preserves that flag, commits
policy revocation/dismissal/push suppression, and relies on the current-authority
read/delivery guard. A regression covers already-claimed and transported notices
without another scheduler poll, including same-revision control replay.
The corrected binary also stopped the same persisted live-test monitor through
HTTP and replayed that exact control successfully; its one observation remained.

The first monitor fixture also supplied free-form constraints. The existing verifier
correctly left it partial for owner review; it did not produce a monitor proposal.
A separate fixture with the supported actual-source completion criterion verified
end-to-end automation. This is not a claim that arbitrary semantic constraints are
independently proven. The first browser fixture held an intent classifier instead
of the answer stream; the local fixture was corrected to implement that protocol.
The discovered noun/duration false-positive itself was repaired in the product.
