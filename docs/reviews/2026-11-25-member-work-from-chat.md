## 최초 비교에서 발견한 결함

- React의 표현 판정과 서버의 표현 판정이 서로 달라 일상어 요청이 일반 답변으로 끝났다. 회원 런타임에 해석을 맡기고, 명시적인 버튼과 기존 문법은 기존 업무 명령을 사용한다.
- 서버가 묶음 보고서를 저장해도 일반 회원용 보고서 조회는 개별 보고서만 찾아 404를 반환했다. 회원·대화 경계를 확인하는 같은 조회에서 두 형식을 열도록 연결했다.
- 재전송 판정이 프로세스 메모리에만 남았다. 회원 SQLite에 원래 요청의 지문, 검증한 계획, 선택한 업무 버전, 실제 적용 결과를 기록한다. 적용 전 멈췄을 때도 같은 업무 명령으로 재개한다.
- 실제 Claude가 복합 검색어를 제안해 기억 속 준비물을 놓친 실행이 있었다. 회원 검색에서 짧은 대체어도 확인하고 결과가 있었던 검색어를 작업 기록에 남긴다.

검증은 사용자 요청, 눈에 보인 결과, 되읽은 저장 상태를 함께 확인한다. 설치에 필요한 Google 권한과 실제 모바일 기기의 수락 상태는 [제품 상태](../status.md)에서 관리한다.
