# Google 볼트 계정 선택과 운영 반영 — 2026-11-26

운영 Google 연결의 볼트 선확인과 계정 선택을 수정했다. 실계정의 Google 로그인은
기기 승인 후 확인했다. OAuth 동의와 Gmail 조회 완료는 아직 확인하지 못했다.

## 구현한 흐름

| --- | --- |
| Google 항목 0개 | 볼트 안에서 이메일·비밀번호를 받아 암호화 저장한 뒤 진행 |
| Google 항목 1개 | 가입 이메일과 달라도 해당 항목 재사용 |

회원 식별과 선택한 Google 이메일을 구분하고, 둘을 Kiri 암호문에 함께 고정한다.
프로토콜 v3의 게이트웨이·게스트와 스키마103의 회원 실행본을 함께 배포했다.
기존 OAuth 선택 행의 NULL은 이전의 가입 이메일 제한을 유지한다.
[명세와 작업표](../../openspec/changes/complete-google-vault-selection/tasks.md)

## 운영 확인과 복구

게이트웨이·볼트·lifecycle·회원 실행본·Kiri helper를 함께 교체했다.
회원 UID, 볼륨과 여섯 마운트를 유지했고 재기동 후 회원 ready와 스키마103을
확인했다. 외부 HTTPS의 HTML·JS·CSS는 검증한 빌드와 일치한다.
인증 없는 유효한 Google 연결 요청은 401이었다. 운영 Kiri의 로그인된
회원 화면에서 Gmail → Google 연결 → 잠긴 볼트 열림을 확인했다.
검증 작업은 암호문 전달 전에 취소했다.

회원 이미지: `sha256:14ee962e016b7f1e313da829f3966a0b1fb62fc8b3b5dd59643838e6232a902d`.
교체 전에 회원과 볼트 쓰기 프로세스를 멈추고 개인 데이터·키를 서버의
root 전용 백업에 보관했다. 기존 바이너리·이미지·설정과 helper도 남겼다.
복구가 필요하면 서비스를 중지하고 이 백업과 이전 실행본을 함께 복구한다.
스키마103 데이터에 구 실행본만 덮어쓰지 않는다.

## 미완료와 재개 조건

운영 Kiri에서 사용자가 제공한 값으로 볼트를 열고 Google 로그인 항목을
암호화 저장했다. 볼트 인계 이후 연결은 Google의 추가 본인 확인 필요로
종료됐다. 비밀번호와 인증 자료를 소스·로그·작업 기록에 저장하지 않았다.
설치용 OAuth 앱도 아직 등록되지 않았다. Google은 최초 클라이언트 생성과
설정을 Cloud 콘솔에서 수행하도록 명시한다. Cloud Shell은 필요하지 않다.
[Google의 최초 등록 조건](https://developers.google.com/identity/protocols/oauth2/resources/best-practices#manual-client-creation)

이 조건이 해결되면 동일한 회원 흐름에서 Google 계정 확인, 서비스 동의,
일치하는 권한 저장과 Gmail 읽기 1회를 확인해야 한다. 합성 공급자나
브라우저 테스트 통과를 이 실계정 완료의 증거로 사용하지 않는다.

## 실계정 실행에서 발견한 대기 처리

Google 본인 확인 화면을 감지하면 Kiri를 즉시 폐기하는 동작을 발견했다.
식별자 제출 이후에는 최대 120초 동안 같은 Kiri에서 승인을 기다리도록
수정했다. 무수리는 대기 상태를 표시하고 Google 기기의 확인을 안내한다.
공급자의 차단을 우회하거나 인증 코드를 읽지 않고, 비밀번호를 재제출하지
않는다. 회원 세션·권한 재확인과 전체 실행 상한은 유지한다.
취소·접속 종료·기한 만료 시 기존 정리 절차로 브라우저를 폐기한다.

수정 검증은 Linux의 도우미 23건, 게이트웨이 26건, 화면 20건을 통과했다.
Claude Sonnet 5.5 / medium 독립 검토가 찾은 정리 유예 중 영수증 조기 만료도
수정했다. 브라우저 정리 확인이 없는 경우 중복 로그인을 막는 표식이 전체
유예 시간 동안 유지되는 회귀 시나리오를 추가했다.

게이트웨이·UI·Kiri 도우미를 함께 운영에 반영했다. 운영에서 볼트를 다시 열자
저장된 Google 항목 하나를 재입력 없이 사용했고, 화면에 본인 확인 대기가
표시되는 동안 Kiri 작업이 유지되는 것을 확인했다. 사용자가 기기 확인을
승인한 뒤 운영 화면이 `setup_required`로 전환됐고 Google 로그인 확인을
표시했다. 이 상태는 선택한 이메일과 Google 계정 홈의 일치를 확인한 뒤에만
반환된다. 로그인 도우미 종료도 확인했다. OAuth 동의·Gmail 조회는 미완료다.

재사용 가능한 설정을 확인했으나 기존 GWS OAuth 클라이언트는 `installed`
유형과 localhost 콜백을 사용했다. 운영 HTTPS 콜백용 웹 클라이언트로
임의 대체하지 않았다. 설치 앱 등록을 마친 뒤 동일한 볼트→Kiri 로그인→
서비스 동의→회원 Gmail 읽기를 확인해야 전체 목표가 완료된다.
