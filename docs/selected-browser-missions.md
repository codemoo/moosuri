# 선택한 브라우저 페이지로 맡긴 일 이어가기

개인 작업 브라우저에서 직접 로그인·탐색한 뒤 **현재 페이지를 맡긴 일에 사용**을 누른다. 대기하거나 잠시 멈춘 내 읽기 업무를 고르면, 지금 표시한 문서를 새로 관측해 비공개 자료로 저장하고 원래 업무를 이어간다. 원래 실행 ID·도구 profile·남은 호출 수·완료 기한을 유지한다. 추가 승인창이나 질문 복사 없이 기존 맡긴 일과 보고서 흐름을 사용한다. 실행 중이거나 결과가 불명확한 업무는 먼저 안정된 경계에서 멈춰야 한다.

화면의 최근30초 frame token과 실제 document identity가 일치해야 읽는다. 다른 문서로 이동한 경우 새 화면을 확인해 다시 선택한다. 선택은 일회용이며, 저장 응답이 유실되면 같은 UUID로 기록된 결과만 확인한다. 다른 계정·세션·조작권·업무 revision은 사용할 수 없다. 업무가 이미 만료되면 자료를 복사하거나 원래 모델을 다시 실행하지 않는다.

복사한 자료에는 관측 URL·시각·부분 읽기 여부와 읽을 수 있는 본문이 들어간다. 입력 필드의 값·쿠키·CDP·조작 token·화면 이미지를 자료로 저장하지 않는다. 사이트가 입력값을 일반 본문에 되비춘 모든 경우를 자동 제거한다고 보장하지 않으며, 사용자가 현재 문서를 확인해 선택한다. 자료 안의 실행 지시는 권한이 아니다. 원래 업무는 보관 자료 읽기 도구로 그 출처를 읽으며, 새 브라우저 조작 도구나 권한을 받지 않는다. 이 작업은 새로운 source만 추가하므로 선택한 안정된 실행의 knowledge generation을 원자적으로 전진시키되 이전 자료·기억을 수정하지 않는다.

기존 자료 화면에서 복사본을 관리할 수 있다. 원래 브라우저 대화나 업무를 삭제하면 복사본과 그 근거로 만든 보고서도 철회한다. 복원한 브라우저 자료는 격리하며 이전 선택 권한을 되살리지 않는다. 브라우저 창을 닫는 것과 명시적으로 저장한 자료를 삭제하는 것은 별개다.

이 브라우저와 로그인 쿠키는 서버에서 관리한다. 서버 운영자가 읽을 수 없는 native vault 자동화가 아니다. 볼트 암호/TOTP를 사용하는 신뢰한 기기 브라우저와 사이트별 자동 로그인은 별도 구현 범위다. 기존 배포는 새 `workspace_observe_selected` operation을 포함한 browser worker/capsule을 빌드해야 한다. 오래된 worker에 임의 관측으로 fallback하지 않는다.

구현은 기존 browser controller·source writer·mission control·파생 문서 철회 경로를 이용한다. schema66은 원래 대화/업무·acceptance·source revision·요청 digest/receipt만 연결하며 브라우저 비밀이나 frame token 원문을 저장하지 않는다. API는 `POST /api/v1/threads/{id}/browser/mission`이며 일반 모델 도구로 등록하지 않는다. [검증](reviews/2026-11-15-selected-browser-missions.md).
