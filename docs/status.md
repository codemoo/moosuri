# 현재 상태

운영 버전과 기능은 2026-11-20, 모델 설정과 검증 상태는 2026-11-21 기준이다. 운영 Linux는 **회원마다 컨테이너 하나를 쓰는 Kiri 0.2.1**로 서비스한다. 공개 한 줄 설치기는 **표준 서버 개발판**을 설치한다. 표준 서버에서 검증한 기능이라도 Kiri의 회원 화면에서 쓸 수 있는지는 아래 운영 범위를 확인한다. [설치판 안내](install.md) · [Kiri 운영 안내](../deployment/kiri/README.md)

| 볼트 | 독립 볼트 웹에서 로그인 항목을 관리할 수 있고 Kiri 회원 화면에서 연결 상태를 확인한다. [볼트 웹](vault-service-client.md) | Kiri 로그인에서 볼트 세션으로 이어지는 인증과 에이전트의 일반 로그인 항목 사용이 남아 있다. |

## 로컬 회원 UI 개편판

11월 21일 운영 설치에서 회원에게 적용되는 모델이 Claude Sonnet 5.5 · medium이고 새 요청을 받는 상태임을 확인했다. Linux 서버의 격리된 개편판에서 같은 설정으로 회원 대화 7건이 통과했다. 1,002턴의 동명이인 대화에서는 원문과 구조화 기억을 제공했을 때 모두 3건에 정확히 답했다. [대화 검증](reviews/2026-11-20-kiri-scenarios.md#claude-대화-검증) · [기억 측정](../audit/memory-reader/results.md#linux-서버-재검증) · [Linux 전체 실행 기록](../audit/standard-journey-checks.md#linux-서버-재검증)

11월 20일 확인한 공개 main과 운영 게이트웨이의 실행 버전은 `4fd6a01`이다. 로컬 개편판에는 날짜별 대화와 분리된 초안 복구, 실행 중 후속 지시, 회원별 **맡긴 일**, 기억 수정 이력, Google 권한 왕복, 활성 회원 검색·초대 접수증, 엔진 재개와 OpenRouter 사용 한도 조회가 들어 있다. 비회원은 `/demo`에서 세 합성 예시를 열 수 있다. 데스크톱은 Muse를 참고한 72px 탐색을 사용하며 모바일은 화면 아래에서 이동한다. [기능별 워크로그](reviews/2026-11-20-member-ui-worklog.md) · [화면별 수락 시나리오](reviews/2026-11-20-kiri-scenarios.md)

관리자 웹 초대의 호스트 자동 준비는 별도 Ubuntu·Kiri 게스트에서 두 회원으로 검증했다. 운영 반영에는 회원 스키마 91, 설치 레지스트리 v7에 맞는 게이트웨이·브로커·회원 실행본 전환이 필요하다. 공개와 운영 절체는 승인 대기 중이다. 실제 Google 두 계정과 실물 휴대폰의 수락도 남아 있다. [초대 실행 기록](../deployment/kiri/linux-vm-smoke/onboard-worker-evidence.json) · [운영 절차](../deployment/kiri/admin.md)

개편판의 **맡긴 일**은 대화·브라우저·Gmail 조회·로컬 조사를 날짜별로 보여준다. 실제 읽은 자료를 단계별로 열 수 있고, 회원이 맡긴 기억·대화 검색은 게이트웨이 타이머가 반복 실행한다. 예약 하나의 실행 기록에서 수동·자동 회차를 함께 조회한다. 예약을 해제하고 같은 이름으로 다시 등록해도 과거 회차는 원래 예약에서 열린다. 표준 서버의 외부 연동 장기 업무와 모니터, 자동 기억, 개인 파일, 푸시·Telegram, 볼트 로그인 연동의 Kiri 이전은 계속 진행 중이다. [회원 업무 사용법](member-tasks.md) · [업무별 Linux 검증](reviews/2026-11-21-member-workflows.md)

## 표준 서버와 출시 준비

표준 서버 개발판은 저장되는 대화·개인 자료 조회·자동 기억 추출·예약 업무·후속 모니터링을 지원한다. 같은 공급자 연결에서 관리자 모델이나 추론 강도가 바뀌면 다음 호출에 반영한다. 이미 공급자에 보낸 요청은 원래 모델로 정산한다. [모델 설정](provider-settings.md) · [자동 기억](automatic-memory.md) · [예약 업무](missions.md) · [모니터링](task-monitors.md)

- **설치와 접속** — macOS·Linux·WSL2용 설치 흐름과 한국어·영어 안내가 있다. Tailscale과 도메인 HTTPS 설정, Telegram 연결은 각 안내에서 지원 범위를 확인한다. [설치](install.md) · [Tailscale](tailscale.md) · [외부 접속](public-access.md) · [Telegram](telegram.md)
- **비서 기능과 품질** — 기능별 동작과 제한은 기능표에, 평가 방법은 시험 계획에 기록한다. 새로운 시나리오를 이용한 독립 품질 평가와 실기기 성능 측정이 남아 있다. [기능표](features.md) · [평가 방법](agent-evaluation.md) · [71개 기능의 실행 시나리오](../audit/feature-journeys.tsv)
- **복구와 안정판 출시** — macOS의 합성 볼트 원본을 오프라인으로 전환한 뒤, 별도 Linux 호스트의 암호화 사본과 운영자 키로 마지막 수신 지점까지 복원했다. 수신이 끊긴 뒤의 마지막 변경은 빠졌고, 복원된 세션 수는 0개였다. 운영 설치 전체의 복구, 공식 패키지 배포와 플랫폼별 실기기 수락이 남아 있다. [두 호스트 복구 기록](reviews/2026-11-20-vault-offhost-recovery.md) · [출시 조건](public-release.md) · [구성요소 패키지](component-packages.md)
