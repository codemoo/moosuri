# 현재 상태

운영 Linux는 2026-11-27 공개 소스 `c8cf8e8`의 **Kiri 0.2.2** 실행본으로
전환했다. Ubuntu 22.04와 커널은 유지하고, 회원 UID·볼륨·암호화 볼트·보호 키·
Google 앱과 회원 권한을 보존했다. 공개 한 줄 설치기는 아직 **표준 서버 개발판**을
설치한다. [전환과 실제 확인](reviews/2026-11-27-matched-production.md) ·
[설치판 안내](install.md) · [Kiri 운영 안내](../deployment/kiri/README.md)

운영 Google 연결은 공개 Rust 실행기와 회원별 일회용 볼트 수신자를 사용한다.
개인 Python 도우미와 고정 소유자 소켓은 새 연결 경로에서 제거했다. 전환 후 기존
Gmail 권한으로 받은편지함 5건을 조회하고 새로고침 후 저장된 결과를 확인했다.
볼트는 잘못된 비밀번호를 거부하고 올바른 비밀번호로 열렸다. 관리자 모델 복구
화면도 열리지만, 기존 Claude 구독 워커가 없어 자연어 대화 조회는 아직 실패한다.
관리자가 승인한 유효한 모델 연결의 등록·실제 추론이 필요하다.

새 연결의 실제 운영 검사에서 프록시에 외부 기본 경로가 없는 결함을 발견했다.
내부망을 먼저 연결한 Kiri 프록시가 Google HTTPS를 502로 거부했다. 공개 설치기와
배포 도구를 외부망 우선 생성으로 수정하고 실제 경로 검사도 추가했다. Linux VM에서
외부 접속·사설 주소 차단·작업 컨테이너 격리·재시작·정리 6개 검증이 통과했다.
운영 프록시 교체도 완료했다. 이후 실제 새 연결은 볼트 인계를 통과했지만
로그인 완료에 도달하지 않아 취소했고 브라우저 정리를 확인했다. 후속 진단에서
Google의 텍스트형 이메일 입력란을 놓치는 결함을 수정하고 인증 실행기에 반영했다.
이제 이메일 제출까지 진행하지만, Google이 다음 단계에서 로그인을 거절한다.
공식 계정 출처의 거절 상태를 확인했으며 비밀번호 입력·기기 승인·동의에는
도달하지 않았다. 반복 시도는 중단했고 기존 Gmail 권한은 유지했다.

아무 설정 없는 Ubuntu 24.04 설치, 새 무과금 프로젝트·공유 OAuth 앱 자동 설정,
초대 회원의 별도 Google 동의와 실제 모델 대화는 하나의 열린 목표다. 기능당 6–8개,
총 58개 여정으로 관리하며 합성·부분 검사와 전체 실제 여정을 구분한다. 수정된
116a8cd 설치와 후속 0b5e8fa의 두 회원 교체·재부팅은 통과했으나, 최종 소스의 완전한
빈 설치와 기본 공개 설치 진입점은 아직 남았다. 운영 초대 타이머는 구성하고 빈 대기열 실행을 확인했으며, 실제 후속 회원 준비는 남아 있다.
[여정별 상태](../openspec/changes/automate-installation-google-app/journeys.md) ·
[구현과 검증 기록](../openspec/changes/automate-installation-google-app/tasks.md)

초대 회원의 웹 가입을 별도 8개 여정으로 추가해 현재 목표는 총 58개다.
이전 두 회원 설치 검사는 두 번째 회원의 비밀번호를 root CLI로 설정했으므로
일반 회원이 웹만으로 가입했다는 증거는 아니었다. 개발 후보는 초대 링크 발급,
회원 직접 비밀번호 설정, 중단·응답 유실 복구와 기존 타이머의 권한 우회 방지를
구현하고 Linux에서 검증 중이다. 독립 Claude 검토에서 발견한 비동기 실행
지연을 수정하고 후속 검토를 통과했다. 일회용 설치의 실제 화면에서 초대·가입·응답 유실·권한 철회·중단 후 재개와
재부팅을 통과했다. 새 웹 회원 두 명의 개별 볼트도 확인했다. 최종 동일 소스
설치와 운영 반영은 남았다. [가입 검증](reviews/2026-11-27-web-invitation.md)
공개 f0812c7a의 사전 설정 없는 새 Ubuntu 설치, 두 회원의 실제 브라우저·볼트,
재부팅 후 복구와 외부 통신 격리 검사는 통과했다. 그 설치의 두 번째 회원은
기존 CLI로 비밀번호를 설정했으므로 웹 가입 후보의 최종 수락과 구분한다.

## Google 실계정 확인 — 2026-11-27

기존 운영 설치에서 회원 볼트 계정 재사용 → 새 Kiri Google 로그인 → 연결된
Z Flip5 기기 승인 → 같은 브라우저의 Gmail 동의 → 연결 완료를 확인했다.
새 무과금 프로젝트의 External·에이전트용 웹 OAuth 클라이언트를 실제 Console에서
생성하고 관리자 화면으로 설치에 등록했다. 앱은 Testing이며 해당 테스트 계정만
검증했다. 비밀값은 Linux에서 처리했다.

실제 GWS 경로로 받은편지함 5건을 조회하고 같은 대화의 저장 기록이 새로고침 후
표시되는 것을 확인했다. 다만 “최근 받은 메일 5개 확인해줘”라는 자연어 요청은
업무 해석 단계에서 실패했다. 이후 API 조회 성공으로 이 문제를 완료 처리하지
않는다. 응답은 HTTP 422 `personal_text_model_unavailable`이며, 설치 설정이
가리키는 Claude 워커 소켓과 실행 서비스가 없다. 대화 해석 계약에도 받은편지함
조회 동작이 없어 두 경로를 함께 고쳐야 한다. OAuth 최초 설정의 제품 자동화, 두 회원, 빈 서버 설치와 이 대화 처리
실패를 [50개 사용자 여정](../openspec/changes/automate-installation-google-app/journeys.md)으로
관리한다. 이 첫 조회 시점 이후의 공개·운영 전환은 위 최신 기록을 따른다.

## 빈 Linux 서버 설치 개편 — 구현과 남은 수락

기준은 다른 사람이 아무 설정도 없는 Ubuntu 24.04 서버에 공개 소스를 받아
설치하는 경우다. 개발자의 Mac 인증, 기존 Google 프로젝트·OAuth 클라이언트,
고정 회원 라우팅이나 비공개 실행기는 전제하지 않는다.

11월 27일 후보 `116a8cd`의 소스 설치를 Ubuntu 24.04에서 완료했다. 앞선 빌드가
모델 서비스 파일 누락으로 실패한 뒤 같은 VM에서 수정 소스로 재개했으며, 제품
설정·회원 데이터가 없는 상태에서 설치했다. 따라서 빌드 중단 복구를 포함한 결과다.
관리자와 별도 출처 볼트 로그인, 설치된 초대 타이머의 두 번째 회원 준비, 독립
GWS·브라우저 수신자, 취소·로그아웃과 실제 재부팅이 통과했다. 실제 Chromium에서
두 회원의 8자 볼트 생성·암호화 저장·잘못된 비밀번호 거부·회원 분리를 확인하고,
다시 재부팅한 뒤 저장한 항목을 각각 열었다. 모바일·데스크톱 화면도 확인했다.
공개 기본 설치 진입점과 최종 후속 변경을 포함한 새 설치 검증은 남아 있다.

개발 후보에는 관리자 API 연결 등록·교체, 새 회원의 모델 소켓 자동 구성과 대화의
받은편지함 조회 연결을 구현하고 Linux 합성 여정으로 확인했다. 독립 Claude 검토에서
발견한 설정 저장·회원 장애 격리·응답 유실·대화 전환 오류를 수정했다. 실제 Console의
브랜딩·External 테스트 사용자·권한 읽기도 확인했다. 같은 브라우저에서 OAuth
클라이언트를 발급하고 비밀을 설치에 등록하는 경로는 후보에 통합했으며, 저장
실패·응답 유실·권한 철회와 중복 생성 방지를 Linux 합성 공급자로 검증했다.
설치된 경로의 실제 자동 발급·비밀 유실 복구, 공유 앱 운영 전환, 실제 모델 대화와
두 회원의 Google 동의는 미완료다. 이후 후보 소스는 공개 main의 개발판으로 제공하며, 운영의 계정 보존 전환은 완료했으며, 최종 빈 설치
검증은 남아 있다. [설치 안내](../deployment/kiri/source-install.md) ·
[구현 단위와 실제 검증 기록](../openspec/changes/automate-installation-google-app/tasks.md)

후속 실제 Console 검사에서 후보 코드의 기존 클라이언트 목록·상세 읽기와 생성
화면 자동 입력을 확인했다. 후속 검사에서는 검증용 클라이언트를 실제 발급하고
비밀 저장과 설정 읽기를 확인한 뒤 삭제했다. 이는 Console 하위 경로 검증이며
설치된 전체 자동 설정의 성공은 아니다. 공유 앱의 공개 전환에는 설치 소개·개인정보·약관 주소가 필요해,
후보에 로그인 없이 열리는 `/about`, `/privacy`, `/terms`를 추가했다. Linux
실제 Chromium의 모바일·데스크톱에서 화면 이동·재진입과 회원 API 비호출을
확인했다. Google 공개 전환 수락은 계속 진행 중이다.
공유 앱 공개 준비 기록과 모든 회원 동의 시작 경계를 Linux에서 검증했다.
새 Ubuntu 설치에서는 Docker 빌드에 모델 서비스 파일이 빠진 결함을 발견해
패키징 허용 목록을 수정했다. 위 후보의 수정된 설치·두 회원·재부팅 수락은 통과했다.

## 회원 UI 개편과 검증 범위

회원은 채팅에 “지난 출장 때 몇 시에 출발했는지랑 챙길 것, 한 장으로 정리해 줘”라고 보낼 수 있다. 개편판은 대화와 기억을 따로 조회하고, 같은 채팅에 출처와 저장한 보고서를 보여준다. 날짜가 다른 동명 출장이면 날짜를 묻고, 한 일의 조건만 바꾸면 그 일만 다시 실행한다. **맡긴 일**에서 원래 요청, 각 회차와 결과를 다시 연다. Linux 격리 회원 두 명의 화면과 SQLite에서 요청 재전송, 대화 재진입과 권한 철회를 대조했다. [회원 사용법](member-tasks.md) · [업무별 검증](reviews/2026-11-25-member-work-from-chat.md)

회원이 “기차는 통로 쪽이 편해”라고 말하면 개편판의 **기억**에 선호가 생긴다. 같은 대화를 오래 쓰거나 새 대화에서 좌석을 물어도 해당 기억을 참고하며, 일회성 요청은 평소 선호를 바꾸지 않는다. 회원이 기억을 고치거나 잊어 달라고 하면 이후 추천에도 반영된다. [회원 사용법](member-tasks.md#대화에서-평소-선호-사용하기) · [선호 회상 검증 기록](../openspec/changes/recall-member-preferences/tasks.md)

출장 대화에서 요일을 고치거나 인원수를 바꾸면 앞서 말한 시각과 단가로 다시 답한다. 커피 온도처럼 평소 선택은 새 대화에서도 쓰고, 반복 감시는 회원이 변경 알림을 요청하면 등록한다. 격리된 Linux Chromium에서 여섯 흐름 25개를 실제 Claude로 검증했다. [회원 조작과 결과](reviews/2026-11-25-live-member-journeys.md)

일반 질문과 구매·메일·캘린더 업무를 입력창에서 구분한다. 감시의 주기와 기간을 대화에서 정하고, 응답을 잃어도 원래 감시를 재확인한다. 새 대화를 만드는 동안 쓴 다음 글은 초안으로 남는다. 오늘 주문을 이미 정했다면 그 주문에 평소 선호를 섞지 않고, 평소 온도까지 물으면 현재 기억으로 답한다. [회원 화면 32개 사례와 수정 전후](reviews/2026-11-25-composer-routing-and-recovery.md)

구매 비교는 상품값·배송비·기한을, 지원 준비는 공고와 허용된 메일 근거를 대조한다. Gmail 회신과 개인 일정 변경은 최종 내용과 연결 범위를 확인하고 공급자 응답을 업무에 남긴다. 로컬 자료의 변경 감시, 공개 페이지 감시, Gmail·Calendar 아침 브리핑을 원래 대화에서 관리한다. 외부 서비스의 접수·권한·응답 유실은 합성 공급자로 시험했다. 실제 Google 회원 동의·메일 배달, 실제 주문과 신청 접수, 휴대폰 알림은 실환경 확인이 남았다. [실사용 조사](research/kiri-conversation-work-2026-11-25.md) · [15개 기능·73개 시나리오의 결과](reviews/2026-11-25-member-work-from-chat.md)

11월 21일 운영 설치에서 회원에게 적용되는 모델이 Claude Sonnet 5.5 · medium이고 새 요청을 받는 상태임을 확인했다. Linux 서버의 격리된 개편판에서 같은 설정으로 회원 대화 7건이 통과했다. 1,002턴의 동명이인 대화에서는 원문과 구조화 기억을 제공했을 때 모두 3건에 정확히 답했다. [대화 검증](reviews/2026-11-20-kiri-scenarios.md#claude-대화-검증) · [기억 측정](../audit/memory-reader/results.md#linux-서버-재검증) · [Linux 전체 실행 기록](../audit/standard-journey-checks.md#linux-서버-재검증)

11월 20일 확인한 공개 main은 `4fd6a01`이었다. 11월 25일 운영 회원 실행본에는 날짜별 대화와 초안 복구, 실행 중 후속 지시, 회원별 **맡긴 일**, 기억 수정 이력, Google 권한 왕복, 활성 회원 검색·초대 접수증, 엔진 재개와 OpenRouter 사용 한도 조회가 들어 있다. 비회원은 `/demo`에서 세 합성 예시를 열 수 있다. 데스크톱은 Muse를 참고한 72px 탐색을 사용하며 모바일은 화면 아래에서 이동한다.
