# 현재 상태

운영 게이트웨이·회원 실행본과 Google 연결 확인은 2026-11-26, 운영 모델 설정 확인은 2026-11-21 기준이다. 운영 Linux는 **회원마다 컨테이너 하나를 쓰는 Kiri 0.2.1**로 서비스한다. 공개 한 줄 설치기는 **표준 서버 개발판**을 설치한다. [설치판 안내](install.md) · [Kiri 운영 안내](../deployment/kiri/README.md)

새 설치의 목표는 기존 Cloud 프로젝트·OAuth 앱·결제 계정·GWS 설정·개인 개발 파일 없이 공개 프로젝트만 받아 사용하는 것이다. 현재 Google 연결에는 개인 Kiri 도우미와 고정 회원 등록 의존성이 남아 있어 이 조건을 만족하지 못한다. 11월 26일 Linux에서 개발자 경로를 제외하자 연결·등록 도우미가 공개 소스에 없는 `fresh_browser` import에서 실패했다. 설치 패키징, 회원별 볼트·브라우저 준비, 새 Google 앱 자동 설정과 두 회원의 실제 연결을 하나의 열린 작업으로 관리한다. [명세와 검증 시나리오](../openspec/changes/automate-installation-google-app/tasks.md)

## 회원 UI 개편과 검증 범위

회원은 채팅에 “지난 출장 때 몇 시에 출발했는지랑 챙길 것, 한 장으로 정리해 줘”라고 보낼 수 있다. 개편판은 대화와 기억을 따로 조회하고, 같은 채팅에 출처와 저장한 보고서를 보여준다. 날짜가 다른 동명 출장이면 날짜를 묻고, 한 일의 조건만 바꾸면 그 일만 다시 실행한다. **맡긴 일**에서 원래 요청, 각 회차와 결과를 다시 연다. Linux 격리 회원 두 명의 화면과 SQLite에서 요청 재전송, 대화 재진입과 권한 철회를 대조했다. [회원 사용법](member-tasks.md) · [업무별 검증](reviews/2026-11-25-member-work-from-chat.md)

회원이 “기차는 통로 쪽이 편해”라고 말하면 개편판의 **기억**에 선호가 생긴다. 같은 대화를 오래 쓰거나 새 대화에서 좌석을 물어도 해당 기억을 참고하며, 일회성 요청은 평소 선호를 바꾸지 않는다. 회원이 기억을 고치거나 잊어 달라고 하면 이후 추천에도 반영된다. [회원 사용법](member-tasks.md#대화에서-평소-선호-사용하기) · [선호 회상 검증 기록](../openspec/changes/recall-member-preferences/tasks.md)

출장 대화에서 요일을 고치거나 인원수를 바꾸면 앞서 말한 시각과 단가로 다시 답한다. 커피 온도처럼 평소 선택은 새 대화에서도 쓰고, 반복 감시는 회원이 변경 알림을 요청하면 등록한다. 격리된 Linux Chromium에서 여섯 흐름 25개를 실제 Claude로 검증했다. [회원 조작과 결과](reviews/2026-11-25-live-member-journeys.md)

일반 질문과 구매·메일·캘린더 업무를 입력창에서 구분한다. 감시의 주기와 기간을 대화에서 정하고, 응답을 잃어도 원래 감시를 재확인한다. 새 대화를 만드는 동안 쓴 다음 글은 초안으로 남는다. 오늘 주문을 이미 정했다면 그 주문에 평소 선호를 섞지 않고, 평소 온도까지 물으면 현재 기억으로 답한다. [회원 화면 32개 사례와 수정 전후](reviews/2026-11-25-composer-routing-and-recovery.md)

구매 비교는 상품값·배송비·기한을, 지원 준비는 공고와 허용된 메일 근거를 대조한다. Gmail 회신과 개인 일정 변경은 최종 내용과 연결 범위를 확인하고 공급자 응답을 업무에 남긴다. 로컬 자료의 변경 감시, 공개 페이지 감시, Gmail·Calendar 아침 브리핑을 원래 대화에서 관리한다. 외부 서비스의 접수·권한·응답 유실은 합성 공급자로 시험했다. 실제 Google 회원 동의·메일 배달, 실제 주문과 신청 접수, 휴대폰 알림은 실환경 확인이 남았다. [실사용 조사](research/kiri-conversation-work-2026-11-25.md) · [15개 기능·73개 시나리오의 결과](reviews/2026-11-25-member-work-from-chat.md)

11월 21일 운영 설치에서 회원에게 적용되는 모델이 Claude Sonnet 5.5 · medium이고 새 요청을 받는 상태임을 확인했다. Linux 서버의 격리된 개편판에서 같은 설정으로 회원 대화 7건이 통과했다. 1,002턴의 동명이인 대화에서는 원문과 구조화 기억을 제공했을 때 모두 3건에 정확히 답했다. [대화 검증](reviews/2026-11-20-kiri-scenarios.md#claude-대화-검증) · [기억 측정](../audit/memory-reader/results.md#linux-서버-재검증) · [Linux 전체 실행 기록](../audit/standard-journey-checks.md#linux-서버-재검증)

11월 20일 확인한 공개 main은 `4fd6a01`이었다. 11월 25일 운영 회원 실행본에는 날짜별 대화와 초안 복구, 실행 중 후속 지시, 회원별 **맡긴 일**, 기억 수정 이력, Google 권한 왕복, 활성 회원 검색·초대 접수증, 엔진 재개와 OpenRouter 사용 한도 조회가 들어 있다. 비회원은 `/demo`에서 세 합성 예시를 열 수 있다. 데스크톱은 Muse를 참고한 72px 탐색을 사용하며 모바일은 화면 아래에서 이동한다. [기능별 워크로그](reviews/2026-11-20-member-ui-worklog.md) · [화면별 수락 시나리오](reviews/2026-11-20-kiri-scenarios.md)

관리자 웹 초대의 호스트 자동 준비는 별도 Ubuntu·Kiri 게스트에서 두 회원으로 검증했다. 11월 25일 운영 Linux에서 게이트웨이·브로커·회원 실행본을 함께 전환했다. 기존 회원의 UID·테넌트·개인 볼륨을 대조하고 그 회원의 로그인으로 서비스를 열었다. 실제 Google Workspace 두 계정의 동의와 실물 휴대폰 수락은 남아 있다. [초대 실행 기록](../deployment/kiri/linux-vm-smoke/onboard-worker-evidence.json) · [회원 운영 검증](reviews/2026-11-25-member-vault.md)

Linux 회원 화면에서 장보기 정정 8건, 수업·픽업 일정 6건, 가격 감시 10건이 통과했다. 개편판은 회원이 지정한 공개 페이지의 원화 가격이 상한에 들어올 때 알린다. 현재 가격을 확인하지 못한 회차와 알림이 발생한 회차는 원래 대화에서 구분해 볼 수 있다. [일상 업무 워크로그](reviews/2026-11-25-everyday-muse.md)

개편판의 **맡긴 일**은 대화·브라우저·Gmail 조회·로컬 조사를 날짜별로 보여준다. 실제 읽은 자료를 단계별로 열 수 있고, 회원이 맡긴 기억·대화 검색은 게이트웨이 타이머가 반복 실행한다. 예약 하나의 실행 기록에서 수동·자동 회차를 함께 조회한다. 예약을 해제하고 같은 이름으로 다시 등록해도 과거 회차는 원래 예약에서 열린다. 표준 서버의 외부 연동 장기 업무와 모니터, 자동 기억, 개인 파일, 푸시·Telegram의 Kiri 이전은 계속 진행 중이다. ## 표준 서버와 출시 준비

표준 서버 개발판은 저장되는 대화·개인 자료 조회·자동 기억 추출·예약 업무·후속 모니터링을 지원한다. 같은 공급자 연결에서 관리자 모델이나 추론 강도가 바뀌면 다음 호출에 반영한다. 이미 공급자에 보낸 요청은 원래 모델로 정산한다. [모델 설정](provider-settings.md) · [자동 기억](automatic-memory.md) · [예약 업무](missions.md) · [모니터링](task-monitors.md)

- **설치와 접속** — macOS·Linux·WSL2용 설치 흐름과 한국어·영어 안내가 있다. Tailscale과 도메인 HTTPS 설정, Telegram 연결은 각 안내에서 지원 범위를 확인한다. [설치](install.md) · [Tailscale](tailscale.md) · [외부 접속](public-access.md) · [Telegram](telegram.md)
- **비서 기능과 품질** — 기능별 동작과 제한은 기능표에, 평가 방법은 시험 계획에 기록한다. 새로운 시나리오를 이용한 독립 품질 평가와 실기기 성능 측정이 남아 있다. [기능표](features.md) · [평가 방법](agent-evaluation.md) · [71개 기능의 실행 시나리오](../audit/feature-journeys.tsv)
- **복구와 안정판 출시** — macOS의 합성 볼트 원본을 오프라인으로 전환한 뒤, 별도 Linux 호스트의 암호화 사본과 운영자 키로 마지막 수신 지점까지 복원했다. 수신이 끊긴 뒤의 마지막 변경은 빠졌고, 복원된 세션 수는 0개였다. 운영 설치 전체의 복구, 공식 패키지 배포와 플랫폼별 실기기 수락이 남아 있다. [두 호스트 복구 기록](reviews/2026-11-20-vault-offhost-recovery.md) · [출시 조건](public-release.md) · [구성요소 패키지](component-packages.md)
