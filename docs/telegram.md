# Telegram에서 무수리 사용

PWA와 함께 Telegram **개인 채팅**에서도 무수리를 사용한다. 서버가 Telegram으로
긴 폴링 요청을 보내므로 공개 포트·도메인·웹훅이 필요 없고 Tailscale 설치에서도 동작한다.
서버가 켜져 있고 인터넷에 연결되어 있어야 한다.

## 연결

1. 관리자가 [BotFather](https://t.me/BotFather)에서 `/newbot`으로 봇을 만든다.
2. 무수리 **관리자 → Telegram** (`/admin/telegram`)에 발급받은 토큰을 붙여 넣는다.
   봇 신원과 기존 웹훅 유무를 확인한 뒤 저장한다. 기존 웹훅을 지우거나 다른 봇 서비스의
   수신 설정을 변경하지 않는다. 한 봇에는 이 무수리 설치 하나만 연결한다.
3. 각 사용자는 자기 계정으로 로그인하고 **내 Telegram** (`/settings/telegram`)에서
   연결 링크를 만든다. 링크를 Telegram으로 열어 **시작**을 누른다.
4. 봇의 연결 완료 메시지를 받은 뒤 평소처럼 대화한다. 관리자·가족·친구가 봇을 공유해도
   기억·대화·자료·모델 선택은 연결한 각 무수리 계정을 따른다.

연결 코드는10분 동안 한 번만 유효하다. 링크·코드를 다른 사람에게 공유하지 않는다.
이메일이나 Telegram 사용자 이름으로 계정을 추측해 연결하지 않는다. 사용자 번호와
개인 채팅 번호를 함께 확인한다. 임시 비밀번호 변경 전에는 연결할 수 없다.

## 대화와 알림

텍스트는 웹과 같은 에이전트·기억·도구·사용량·실행 한도로 처리된다. Telegram 대화가
웹 대화 목록에도 남는다. 응답 중에는 입력 중 표시를 보내며 완성된 답변을 전송한다.
긴 답변은 Telegram 길이 제한 안에서 나눈다. 지원하는 실행에는 추가 메시지를
현재 작업의 지침으로 접수한다. 지원하지 않는 실행이면 완료를 기다리거나 중지하도록 안내한다.
연결할 때 브라우저 시간대를 저장해 자연어 예약 요청에도 사용한다.

| 명령 | 기능 |
| --- | --- |
| `/new` | 새 대화 시작; 이전 대화는 웹에 보관 |
| `/stop` | 현재 대화의 진행 중 응답 또는 맡긴 작업 취소 |
| `/status` | 진행 상태와 웹 주소 |
| `/help` | 사용 안내 |
| `/disconnect` | 개인 연결 즉시 해제; 이후 메시지는 처리하지 않음 |

**새 소식 알림**은 별도로 켠다. 개인 제목·본문 없이 소식함 링크를 보내며, 이미 읽거나
숨긴 소식·음소거한 주제·조용한 시간의 알림은 보내지 않는다. 켜기 전에 쌓인 소식은
다시 발송하지 않는다. 이미 Telegram에 전달한 메시지를 웹에서 회수하지는 않는다.

메일 발송은 웹의 **전체 최종 미리보기 승인**을 그대로 요구한다. Telegram에서 “응”을
보냈다고 발송 승인을 대신하지 않는다. 이미지·음성·파일·그룹 채팅과 상세 작업 카드·
연결 입력은 현재 웹에서 사용한다. Tailscale 전용 주소의 링크를 열려면 그 기기도
같은 tailnet에 연결해야 한다.

## 연결 유지와 문제 해결

- 웹에서 로그아웃해도 Telegram 연결은 유지된다. 마지막 Telegram 입력 후30일간
  사용하지 않으면 다시 연결한다. 비밀번호 변경·전체 세션 종료·계정 정지/삭제는
  기존 권한을 철회한다. 백업 내보내기/복원에는 봇·개인 연결을 활성 상태로 이식하지 않는다.
- 개인 설정에서 연결을 해제할 수 있다. 관리자가 봇 토큰을 다시 저장하거나 봇을 끄면
  개인 연결을 다시 설정해야 한다. 토큰은 암호화해 저장하고 화면·로그·모델에 반환하지 않는다.
- 봇 상태의 충돌은 기존 웹훅 또는 다른 수신기를 확인한 뒤 다시 저장해 해결한다.
  인증 오류는 BotFather에서 토큰을 확인한다. 일시적인 수신 장애는 제한적으로 재시도한다.
- 메시지 접수와 수신 위치를 함께 저장하여 같은 업데이트가 업무를 중복 실행하지 않는다.
  Telegram 발송은 일반적인 중복 방지 키가 없어 전송 결과가 불명확하면 자동 재발송하지
  않는다. 웹에는 답변이 남으며 개인 설정에 전달 불명 상태가 표시된다. 명시적인429 응답만
  Telegram이 지정한 시간 뒤 재시도한다.

Telegram 봇 대화는 종단간 암호화된 비밀대화가 아니다. 연결은 해당 개인 대화의 내용과
답변을 Telegram에 전달하는 선택이다. 볼트 암호·TOTP를 채팅으로 가져오는 기능은 추가하지 않는다.
