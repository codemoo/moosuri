## ADDED Requirements

### Requirement: Bounded combined tool definitions reach the model intact

The model protocol SHALL preserve up to48 validated definitions for shared dialects
and the personal ChatGPT plan namespace. It SHALL reject larger lists before provider
IO without truncation. Schema-byte, name, capability and execution limits SHALL remain
enforced.

#### Scenario: Complete foreground definitions reach every supported encoder

- **WHEN** production builders compose the current default vocabulary with conversation recall, all bundled skills, one usable private recipe, connected Gmail, HTTP/search/browser, read-only artifacts and Calendar
- **THEN** every supported shared encoder and personal namespace encodes all32 definitions with default text capabilities
- **AND** enabling credential-broker chat includes its four terminal credential and four native Gmail definitions, preserving all40 definitions
- **AND** exposing a definition grants no credential, owner scope or new execution authority.

#### Scenario: Combined production definitions complete a plan or shared round trip

- **WHEN** the complete32-definition default or40-definition broker vocabulary is used for a synthetic decimal request
- **THEN** an owned plan or shared-compatible HTTP provider observes every exact definition and account pin on both requests
- **AND** a completed decimal call, explicit synthetic result and final continuation validate without a definition-count failure
- **AND** this transport scenario does not claim Store admission or external adapter execution.

#### Scenario: Definition count remains bounded

- **WHEN** a caller supplies48 individually valid definitions within all byte limits
- **THEN** all definitions are encoded in every supported dialect
- **WHEN** a caller supplies49 definitions
- **THEN** validation rejects the request rather than dropping a definition.

#### Scenario: Larger vocabularies retain size and name fences

- **WHEN** individually valid definitions exceed64KiB aggregate schemas/descriptions
- **THEN** the request is rejected
- **WHEN** a completed model call names a function absent from the admitted definitions
- **THEN** the round is rejected even when the admitted list contains48 definitions.
