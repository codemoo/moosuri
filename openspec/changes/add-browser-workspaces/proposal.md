# Persistent personal browser workspaces

## Why
One-shot public page reads cannot preserve login or let a human complete an interruption on the same page. Adopt Muse's broker and Pickle's takeover/continue interaction while preserving the explicit email approval boundary.

## What Changes
- Add bounded per-user, per-conversation Chromium workspaces, private human frames/input, exclusive control and explicit continuation.
- Add profile 5 open/observe/handoff tools, SQLite state/revision fencing and React chat controls.
- Keep authenticated model input/navigation unavailable and retain typed Gmail final approval.

## Impact
Rust connector/worker, store migration 8, runtime, private HTTP API and React chat. Existing collectors, production services and CI configuration are untouched.
