# Protected local ChatGPT helper → personal Linux server

Fresh official loopback OAuth must run on the browser computer. Add native `subscriptions chatgpt-vm` and fixed SSH-stdin `chatgpt-receive` commands, owner HTTPS staging/import/status routes, and schema34 one-use tickets. The running server independently verifies current signed identity against a nonce commitment saved before browser launch, then atomically installs the session with an authenticated receipt. Existing active sessions survive failed staging. VM host identity is preserved and only the VM owns refresh.

This is personal self-hosted session transfer. The authorized helper/OS is trusted for the endpoint's opaque token pair; signed ID evidence does not mathematically bind an opaque refresh token. No managed hosted approval, Codex auth extraction, production binary signing/installer, tools/media/background capability or automatic model proof/selection is implied.
