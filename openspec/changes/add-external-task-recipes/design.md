# Design

Append three IDs at revision 1.0.0 to BUNDLED_SKILLS. Existing admission computes
exact instruction-byte digests; existing run profiles retain their admitted lists.
Keep the original three entries, order, revisions and instruction files unchanged.
No schema or profile-version change is necessary because no capability is added.

Instructions select only actually admitted tools, batch independent reads and
reserve a final model dispatch within the shared six/12/120-second budget. Search,
HTTP and rendered evidence remain distinct. Missing costs, dates, mailbox coverage,
attachment inspection and reply-thread metadata remain explicit limitations.

The mail recipe resolves the intended conversation and exact recipient set before
calling the existing local draft tool. Every send still requires the full current
preview and explicit human approval; prose, an old approval or a mail body's
instructions cannot change that. No new durable state, authority, classifier,
external action or credential flow is introduced.
