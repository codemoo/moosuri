# Personal local artifacts

## Why

A useful saved report, explicit goal or waiting-for-reply record needs an actual
persistent identity and revision rather than a conversational promise.

## What Changes

Add tenant-owned versioned local documents/goals/followups, authenticated editor,
history and safe exports; schema-pinned read tools and isolated current-request
write grants, receipts and transitive withdrawal through existing recovery intent.

## Impact

F15 and the local-record/briefing portion of F28. No F27 mission executor,
recurring scheduler, notification, automatic commitment detection or external send.
No new dependency or provider connection. See docs/artifacts.md for exact bounds.
