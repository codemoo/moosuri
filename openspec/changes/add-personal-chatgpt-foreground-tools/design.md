# Design

Schema36 adds a default-disabled capability bit to the existing exact owner/binding/revision/model/effort text-probe row. A personal owner-only route reuses the bounded shared two-round synthetic challenge verifier with source-aware guards; shared connections retain admin-only validation. Text re-probes preserve tool proof; frozen text runs do not acquire tools later.

The existing loop uses plan-specific request preflight and private checkpoint restore, resolves personal access before each model round through the existing RunLease and refresh CAS, and commits checkpoint/typed calls before tools. Read-only artifact initialization and existing Calendar profiles retain reads without enabling their mutation planners. Existing Store slots, deadlines, dependency revocation, Gmail preview approval and browser handoff remain authoritative. No new tool or task runtime is introduced.

Attachments, conversational memory/artifact/Calendar mutation planning and autonomous personal missions remain separately staged. Existing shared-only mission binding gates stay intact. Restore deletes all personal proofs with their existing table. Actual consenting-account acceptance and independent review are separate verification gates.
