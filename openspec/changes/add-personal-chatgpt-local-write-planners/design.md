# Design

Reuse PlanningSession and source-neutral Store mutation APIs. Resolve an optional personal client through existing RunLease/refresh CAS before each planner dispatch; choose preflight by the client's fixed dialect, then durably admit the model step. Keep isolated classifiers and private decision capsules separate from normal answer continuation. Prepared memory recovery remains before client construction.

Unwrap only artifact/memory planning for personal tools. Calendar and mission planning remain unavailable. Existing planned read-only artifact profiles are not reset. Common shared/personal artifact-write definitions exclude live mail/web/browser/Calendar reads; connector allowed-name validation rejects undeclared calls, while Store's external provenance rejection remains an independent guard. No schema, connector, DTO or capability protocol expansion is needed.

Current literal owner intent and trusted Store grants authorize local writes without a new confirmation UI. Model semantic quality and actual subscription acceptance are separate evaluations, not established by scripted fixtures.
