# Public GitHub instruction acquisition

Users can add a compatible public GitHub instruction package outside the curated catalog. Preview resolves an exact commit and shows source, version and missing capabilities; one explicit install action activates that immutable package locally. No Git process, archive extraction, credential inheritance or task execution is added.

The existing curated installer remains unchanged in identity and digest format. External source identity includes normalized repository and subdirectory, so an unrelated author cannot replace bundled procedures by choosing the same name. Private GitHub and generic code plugins remain unsupported.
