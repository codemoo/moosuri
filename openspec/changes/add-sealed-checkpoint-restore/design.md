# Decisions

The trusted head pins ciphertext and exact full-snapshot identity. Age is read to
authenticated EOF before a canonical six-entry USTAR parser extracts bounded
regular files. Inventory/hashes, DB/seal/schema and complete/applied journals must
match before the isolated copy can change. Dedicated enumerated forward migration
runs offline; ordinary Store is never opened on the sealed copy.

A reserved private sibling stage is rejected by runtime/raw entry points. It is
fully verified, quarantined, synced and atomically renamed without replacement.
Interrupted attempts leave private residue; retries create their own stage and
never adopt or delete others. Matching immutable destination provenance enables
post-rename retry; occupied unrelated roots fail unchanged.

Quarantine advances all account epochs through MSAUTH01, deletes sessions, marks
recovery required, preserves roles/suspension and advances management revisions.
It cancels pending chat/mail, fences historical run retries and private plans,
closes browser control, requires source/mail reconnect and pauses background
extraction/schedules. Committed receipts and usage survive. Provider key material
is absent from B: provider ciphertext is retired, revisions disabled, selections/
probes cleared and a new private encryption key created. Fresh local enrollment
uses the existing operator command and mandatory password change.

The source successor journal retains its original bytes and installation lineage.
Immutable restore events bind the old lineage to each new installation identity;
verification permits only this explicit binding, never a blanket mismatch.
