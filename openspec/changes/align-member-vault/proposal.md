## Why

볼트의 새 비밀번호 입력 조건이 화면과 암호화 엔진에서 달랐고, 잠금 화면과 보관함의 시각적 구조가 회원 페이지와 달랐다.

## What Changes

새 볼트와 키 변경에 같은 8자 기준을 적용한다. 기존 자료의 암호 형식을 유지하며, 별도 출처의 볼트에서 회원 페이지와 같은 로그인·목록·설정 표현을 사용한다.

## Impact

F44–F49의 Rust 암호화 코어, 웹 클라이언트와 정적 파일 배포에 적용한다. [기능 계약](specs/vault-service-client/spec.md) · [검증 기록](tasks.md)
