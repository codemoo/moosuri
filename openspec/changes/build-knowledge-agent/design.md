# Design

The existing single writer provides the dispatch linearization point and an opaque
step capability. Complete transport validation precedes slot commit and tool execution.
The same runtime handles tool-free and tool-capable models. Six dispatches, twelve
local reads and120seconds span explicit retries; unknown remote work is never replayed.
Private capsules preserve protocol/model/effort correlation. Three closed read-only
functions execute only through stored typed slots and the current authenticated lease.

Actual returned evidence and selected successful context form the dependency union.
Knowledge invalidation shares journal replay and purges derived output/private state,
keeping user text and accounting. A conservative generation fence interrupts in-flight
knowledge-dependent work on any knowledge mutation. Completed unrelated work survives.
Short HTTP mutation/SSE delivery gates order local publication, without promising to
recall prior bytes or hold a lock over network inference. Full browser resnapshots
replace cached pages even if the reset event was missed offline.

The two-round capability check is separate from text proof and pinned to current
admin authority/provider revision/model/effort. Existing runs never auto-upgrade.
See [implementation contract](../../../docs/knowledge-agent.md).
