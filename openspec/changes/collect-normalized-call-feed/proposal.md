# Explicit normalized call transcript/audio feed

F40 lacks an owner-selected usable producer. Add a once-only `calls import`
command for a closed versioned normalized export, reuse the existing private-file
and custom source receipt/cursor engine, and optionally reuse bounded fixed Audio
API transcription with per-chunk durable no-resend fences. Preserve exact raw hash,
call identity and reported/unknown speaker provenance. Unknown/mixed attribution
must never acquire automatic personal-memory authority through a collection grant.

No vendor format inference, scanning defaults, phone/microphone operation, cron,
original audio archive, schema/dependency expansion or live acceptance is included.
