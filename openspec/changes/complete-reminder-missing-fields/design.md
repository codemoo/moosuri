# A typed draft is not an execution grant

A separate bounded schema51 chat-run sidecar avoids weakening receipt-only schedule records or Calendar/mission continuation types. Only the immediately preceding completed creation question can supply fields, under the exact owner/session/epoch/thread,15minute expiry and two-answer bound. The current message must match the missing literal/time grammar. Eligible-draft cancellation is resolved before saved-reminder deletion; other new explicit commands take precedence and unrelated answers retire the prior question. Media and explicit other targets exclude continuation. Restore disables pending flags; FK deletion removes erased-chat state.

Already supplied civil/relative time and source timezone remain fixed. If time was entirely missing, the first time answer is resolved from its own admission timestamp under the original zone. Narrow component answers fill missing day/AM-PM without changing known fields, including ISO dates. An incomplete final answer closes the draft rather than asking for a third answer. A small bare content language excludes outer meta/source/search/send prefixes; explicit content labels retain literal payloads. This avoids treating arbitrary prose as an old action. Completion reuses the existing atomic chat/create/receipt transaction and request-id replay, with rollback preserving pending state when publication fails.
