# Design

Schema58 adds a content-free `agent_planner_steps` table with one immutable marker per planner domain and unique model step. Artifact NoCommand preparation records its completed, no-tool step in the same transaction that marks the artifact route planned. Mission/Calendar admission uses `begin_mission_chat_step`; an internal shared dispatch helper commits its domain marker, StepLease nonce, model receipt and run-wide accounting atomically.

Untouched mission planning and skip permit remote0 or exact completed artifact NoCommand from the current attempt and run lease, with no tool slots or sealed artifact write. A generic completed call is insufficient. Recording requires the admitted current StepLease and no attached tool calls. Mission preflight/application and Calendar sealing/recovery require the immutable matching model receipt and originating lease, while independently checking the original session/account/epoch and live run authority. Completed local confirmation remains possible after explicit Retry; a dispatched/unknown marker never authorizes reclassification. Calendar plans store the actual source step instead of literal1.

Migration adds the marker table and rebuilds `calendar_command_plans` with the original columns, keys, foreign key and exact rows, changing its obsolete step1-only constraint to the existing step1–6 model budget. Both normal opening and sealed restore execute schema58. It does not backfill counters, checkpoints or old plans into typed markers. Existing rows remain stored; ambiguous old pending effects fail closed. Passed ordinary routes continue ordinary execution. A pre-migration run with no dispatch can still use normal current authority admission. Global six-model/twelve-tool/deadline limits are unchanged. The broad artifact cost cue is retained so regression tests exercise the actual collision.
