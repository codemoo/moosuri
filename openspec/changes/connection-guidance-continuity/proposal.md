# Preserve owner guidance through provider connection waits

A stable provider-connection continuation increments the mission carrier attempt
without transferring accepted or applied live instructions. The resumed model
reads only its new execution attempt and silently loses that owner context.

Reuse the existing stable mission requeue helper for connection promotion. Keep
original receipt admission identities, model/profile, deadlines, checkpoints and
model/tool/repair accounting. This repairs the documented runtime foundation;
there is currently no agent/server caller that automatically invokes the yielding
Store API. No new connector workflow or ordinary UI capability is claimed.
