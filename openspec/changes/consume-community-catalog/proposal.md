# Consume an explicitly configured public static catalog

Contributor-generated catalog artifacts currently require manual GitHub import. Add one operator-selected public GitHub catalog source, bounded opportunistic daily/ETag discovery and durable last-verified offline cache, then show offers in the existing Suggestions cards. Only selected packages are fetched; original exact-commit GitHub acquisition independently verifies their source before the existing per-user preview/install lifecycle can activate them.

This adds no registry service/account, private query/LLM call, code/script/hook execution, automatic install/update/run/mail or new capability. Source digest and format checks are not safety/license/success certification. Schema35 stores only public discovery cache metadata and restart leases; schema34 authority is retained.
