# Keep existing document edits in their local domain

## Why

A current request to read, revise and save an existing named document matched the
fresh research-report cost gate. The artifact profile became read-only before
the mission classifier could return the request to the document domain. A
different defect let a composer-selected document silently override a different
document explicitly named in the current edit request.

## What Changes

Keep explicit existing-record edit verbs outside quoted data out of the fresh
compound-report route. Preserve quoted titles, completed-edit input modifiers and
fresh source/calculation-to-new-document routing. At Store admission, require a
provided literal named target to agree with a composer pin; preserve selected
editing with a null quote or an unquoted supported deictic reference.

## Impact

F21 and the existing one-artifact current-intent, anchor/CAS and receipt contracts.
No new tool, authority, provider call, schema migration or approval step.
