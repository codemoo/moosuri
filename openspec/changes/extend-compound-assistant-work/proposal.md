## Why

Current missions can perform bounded reads but cannot save requested reports, prepare actionable drafts or resume a composed task through a credential wait. Private learning recognizes narrow operation families. Native Gmail display results intentionally do not enter model context. Extend existing services into complete user tasks without rebuilding the harness or claiming unsupported capabilities.

## What Changes

- Add bounded step/output contracts and private report outcomes to existing missions.
- Add exact account selection, automatic scoped reuse and intermediate waits.
- Introduce separately granted native model-readable Gmail operations.
- Compose existing draft, final-approved send and bounded Calendar services.
- Qualify supported compound recipes and share synthetic structures through existing cards/Git lifecycle.
- Stage authenticated browser work around a trusted-device boundary and individually supported adapters.

## Capabilities

### New Capabilities
- `compound-assistant-work`: Outcome-bound composition of existing task, credential and skill services.

### Modified Capabilities

None. Existing domain contracts remain and require explicit implementation deltas where expanded.
