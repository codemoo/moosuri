## Why

A mailbox question could explain missing access without offering a connection card. Self-hosters may already use a signed-in GWS device.

## What Changes

Offer a scoped Gmail setup card and optional personal vault path. Allow the installation to bind a member to a loopback GWS INBOX metadata bridge.

## Impact

Changes foreground mail routing, authenticated settings, device CLI and chat UI. Existing Google Web OAuth and send approvals continue to serve their current operations.

Verify the device profile before the first read, support owner-initiated Google sign-in on the device and resume a pending latest-inbox lookup in its original conversation.
