# Natural requests keep their actual domain

Fresh independently authored assistant requests exposed two domain-routing defects:
weekdays inside an explicit memory correction entered schedule planning, and Korean
instructions to separate source claims required arithmetic and prevented report saves.
Correct those paths without new model calls or expanded mutation authority. Numeric
parameter resolution also counts complete tokens before deciding uniqueness, so digits
inside a different amount do not make an otherwise unique quantity ambiguous.

Preserve the original evaluation, including author-invalid inputs and unexecuted
fixtures. Rechecks of exposed requests are development regressions, not a new holdout.

The same evaluation also exposed a Korean no-send clause disabling local draft
preparation. Retain that prohibition while admitting only the requested local draft
and its original recipient wait; actual sends still require final approval. Clarify
source-query quoting within the existing tool description size limit.
