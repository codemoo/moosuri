## Why

무수리를 설치한 서버 하나가 가족·친구의 비서를 운영해야 한다. 사용자는 자신의 기기를 켜 두지 않아도 메일을 연결하고, 나갔다 돌아와도 같은 대화와 작업을 이어가야 한다. 현재 계정별 행 격리에서 사용자별 실행·파일·인증 경계로 옮긴다.

## What Changes

- 활성 무수리 계정마다 Kiri 컨테이너 하나와 전용 영속 볼륨 하나를 할당한다. 첫 관리자도 같은 방식으로 자신의 비서를 사용한다.
- 개인 로그인, 외부 서비스 인증, 에이전트 실행 및 작업 기록을 해당 컨테이너가 소유한다. 설치 전체는 모델 인증·추론 용량과 검증된 공용 배포물을 공유한다.
- 서버 Google OAuth를 첫 수직 구현으로 삼는다. 기기 도우미 설치와 상시 터널을 일반 회원의 가입·메일 연결 과정에서 제거한다.
- 기존 데이터와 실행 중인 작업은 계정 단위 검증과 단일 실행자 전환을 거쳐 이동한다.

## Impact

서버·스토어·러너·모델 실행기·웹 로그인·설치·백업 계약에 영향을 준다. 개발판은 신규 회원용 Linux 런타임부터 도입한다. 기존 설치를 전환하는 조건은 계정별 복구 리허설과 시범 계정 검증이다. [설계와 검증 기준](design.md) · [작업 순서](tasks.md)
