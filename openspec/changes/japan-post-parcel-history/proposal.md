# Japan Post official visible shipment history

F42/P6 currently exposes only a latest summary, so a shipment-history request
cannot return the preceding provider events. Add a separate one-read typed history
tool based on cited public source structure, retaining latest-summary/learned-v1
semantics. This is unauthenticated public research, not a carrier account/action.

Success is bounded provider-ordered history with exact number/source/time and
honest failure when full supported page rows cannot be established. Missing
worldwide/overseas records and live positive-provider acceptance remain explicit.
No schema, dependency, credential, subscription or external write is added.
