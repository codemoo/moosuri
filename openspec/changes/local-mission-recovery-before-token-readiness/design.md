# Recovery ordering

A claimed mission first consumes its verified completed capsule and guarded local
receipts. Current Store run/step and mission checks remain the authority for plan
admission, local tool replay, input waits and final verification. Only a task that
still needs inference constructs a model client or enters personal token readiness.
The existing per-round readiness check remains before each new dispatch.

No schema, automatic inference retry, unknown-effect replay or alternate provider
is added. Disconnected bindings and expired original current-session grants still
fence completion. Already observed model usage and original limits remain.
