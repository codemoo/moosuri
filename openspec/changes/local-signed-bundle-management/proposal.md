# Local signed preview bundle management

Progress P10 with a concrete native Rust install/manage path: independently pinned
Ed25519 local bundles, embedded React binaries, private disjoint runtime/data roots,
review-only deployment files, stopped same-schema encrypted-export update and
activation recovery, and exact-file data-preserving uninstall. Reuse init, writer
admission, integrity/journal verification, backup and shutdown contracts.

No official release key/artifact, downloader, live service/network provisioning,
CI, cross-schema recovery, stable release or arm64 acceptance is added.
