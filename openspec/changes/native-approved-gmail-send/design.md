# Design

A separate `select-google-send` local grant and signed registration publish only the expected account address and nonsecret binding as a native transport in the existing mail connection list. Actual refresh checks require exactly openid/email/gmail.readonly/gmail.send and exact UserInfo/profile identity on each operation. Existing three-scope read grant ceilings do not change. Native connections have draft-only model capability; generic mailbox/provider-draft/mission reads remain server-connector capabilities.

Schema56 adds a native flag to existing mail connections, a device/binding/epoch connection map, and immutable per-action-revision effect adoption. Approved MIME stays in the existing action until that device fetches and validates it. A small signed execution envelope binds owner/action/revision/connection/auth/MIME/Message-ID/timing/expiry/fingerprint, while large raw MIME is delivered separately under the exact typed device command and held only in native process memory. The command signing limit stays16KiB. A single writer transaction commits native/broker/send-evidence authority; another device cannot steal the effect.

The normal mail worker excludes native connections, and the native poll uses approved-action/background authority without weakening the existing read broker's enrollment-session checks. Precommit edits require a new revision and final approval. The companion performs actual credential checks, live freshness and signed current checks, fsyncs entry, and sends the exact bytes once. Retained/entered work reconciles without network replay. Authenticated late receipts settle the original action privately after authority loss.

Native Sent lookup uses original evidence and the existing persistent attempt/lease budgets, conservative shared MIME fingerprint oracle and sticky/conflict merge. It rechecks online authority between list and candidate raw fetch. Results never create send authority or convert observational equality into a provider send receipt. Restore quarantines native connection pins and pending approvals.

Shared maintained helpers validate frozen new plaintext and Sent equality; no second MIME parser is introduced. Fixed provider endpoints and existing no-retry HTTP transport are reused. Privacy concerns are separated: credentials remain native; outgoing draft content already lives in the private assistant mail workflow. Trusted binary/OS and malicious-server-within-a-local-grant limits remain explicit.
