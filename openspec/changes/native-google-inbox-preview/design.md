# Design

The fixed Google adapter reuses refresh/UserInfo/profile checks, then lists up to5 INBOX IDs and reads only metadata headers/snippet through fixed GETs. A new preview-only local grant and typed resource/operation/projection prevent a counts binding or old run profile from gaining content authority. New discriminants append without changing old bytes. Bounded strings carry truncation/partial/page-availability signals and no account/message IDs. Exact credential/token echoes fail before text normalization.

The same durable broker request/commitment/journal/receipt completes the original chat terminal slot. Content is literal untrusted display data; there is no subsequent model continuation or follow-up authorization. Settings and chat both render React text without markup interpretation. Lost responses retain UUIDs and entered operations never replay. No migration, provider-write path, generic endpoint or new dependency is needed.
