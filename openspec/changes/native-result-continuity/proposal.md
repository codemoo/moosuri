# Native result continuity

## Why

A native Gmail wait rebuilds its mixed tool round after signed settlement. That path serialized saved-source search/read results without their receipt addresses, although ordinary foreground results include those addresses for admitted source-bound arithmetic. The next inference could not consume the existing evidence without guessing or reading again.

## What Changes

Share one result serializer between fresh and resumed foreground rounds. Preserve the existing profile gate, exact stored step/call identity, null direct-receipt ordinal and error envelope behavior. No new tool, grant, mutation, migration or provider retry is introduced.

## Capabilities

### New Capabilities
- `native-result-continuity`: mixed native/saved-source rounds retain consumable receipt addresses after their original signed wait.

### Modified Capabilities
None.

## Impact

Existing P4 evidence arithmetic and P8 separately granted native mail continuity. See [native mail](../../../docs/native-google-model-mail.md) and [evidence calculation](../../../docs/evidence-calculation.md). Rust agent serialization and one synthetic Runtime regression only.
