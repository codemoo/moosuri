# Design

Keep the existing typed `NativeMailRead` capability and classify all four emitted native tool names into it. Mission policy already permits that capability; live instructions and task monitors already deny it. Account, profile, operation8, exact grant, selector lineage, cancellation and settlement checks remain at their existing execution boundaries.

The catalog regression consumes actual emitted schemas rather than maintaining another name list. The supervised Runtime fixture uses current first-round execution semantics and checks all four tool names in initial and resumed inference. It retains actual signed synthetic native settlement, original run identity, no-polling call counts and delegated mission outcome checks.
