# Native tool routing

## Why

The shared named-tool classification omitted the four existing native Gmail model-read tools. Mission schema filtering therefore removed authorized native reads while typed Store admission still allowed their capability.

## What Changes

Classify the existing native read catalog consistently and verify initial/resumed chat and delegated mission exposure. Preserve the default-off feature, model proof, exact scope and trusted-device/background grants. No new tool, credential authority, transport or storage schema is introduced.

## Capabilities

### New Capabilities
- `native-tool-routing`: existing admitted native read schemas survive mission filtering without entering live-instruction or monitor surfaces.

### Modified Capabilities
None.

## Impact

R/F links: P4 tool dispatch and P8 separate credential use; existing [native mail contract](../../../docs/native-google-model-mail.md). Rust shared classification and focused synthetic regression only.
