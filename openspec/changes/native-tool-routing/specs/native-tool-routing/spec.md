## ADDED Requirements

### Requirement: Consistent native read routing
An admitted native Gmail model-read catalog SHALL use the same `NativeMailRead` capability for named-schema filtering and typed execution. Classification SHALL NOT grant account, scope, device or background authority.

#### Scenario: Delegated native mission waits and resumes
- **GIVEN** the default-off native feature is enabled, a model-proven operation8 profile and a separate current background grant
- **WHEN** the owner delegates the supported native Gmail summary task
- **THEN** the four native read schemas remain available in initial and resumed inference
- **AND** the original task waits without model polling and continues from its authenticated signed receipt

#### Scenario: Other surfaces remain excluded
- **WHEN** native schemas are considered for live-instruction or task-monitor policy
- **THEN** they remain excluded
- **AND** a disabled feature, missing read flag or invalid/missing operation8 scope emits no native read catalog
