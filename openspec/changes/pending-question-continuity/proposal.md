# Preserve and cancel bounded pending questions

An accepted ambiguous Calendar answer currently loses its immediately preceding
pending-field identity, so a literal correction cannot continue the original
request after reopen. Whole cancellation replies also fall through interpretation
while the old question is still inherited.

Retain an established still-missing field across an ambiguous answer and display
that field's existing question. Recognize a complete literal cancellation reply to
the immediate owned question and close it locally, sharing generic reply grammar
with reminder drafts. Preserve original authority, expiry, literal answers and
scope; never cancel a saved task/reminder/event or grant a new effect.
