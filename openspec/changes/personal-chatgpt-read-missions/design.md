# Design

Resolve mission model capabilities through owner-aware binding checks for Shared
or PersonalChatGpt only. The exact saved text/tool proof is necessary transport
capability; only the original explicit owner mission request creates background
authority. Keep original account epoch, binding/model/effort and read profile.

Use SubscriptionAuthority::Run on the existing mission lease for token readiness
and refresh before each new inference. Official plan encoding/namespace handling
and existing durable begin-step allowance/usage receipts stay authoritative. Every
mission still has six model/twelve tool calls and its original deadline. Pending
local checkpoints replay evidence; started/unknown calls never automatically reenter.

Store a private default-false command-admission marker only for newly admitted
personal exact-tool-proof chat runs. This allows existing current-request mission
creation/control while preventing retroactive expansion of old Calendar-only/text
runs. Original quote/session/target/revision checks still create actual grants.

No schema/public DTO or dependency change. No token extraction/shared subscription
pool, mail/Calendar write mission, browser/vault/media/Claude background, new approval
step or real auth/inference is added. Root owns independent review and joined Linux
acceptance; full real-device/account eligibility remains separate.
