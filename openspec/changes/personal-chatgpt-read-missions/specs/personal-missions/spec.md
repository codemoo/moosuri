## ADDED Requirements

### Requirement: Original owner delegation authorizes personal read missions
The system SHALL execute accepted read-only one-off/recurring missions with the
owner's exact saved personal ChatGPT binding/model/effort tool proof only under the
original explicit mission grant. Proof alone SHALL NOT confer background authority
or create shared/family subscription access.

#### Scenario: Subscription-only explicit repeating task
- **WHEN** a current owner explicitly delegates a repeating supported read task
- **THEN** its original request, owner/account epoch, model/proof and scope are saved
- **AND** the due occurrence uses the existing bounded mission execution contract
- **AND** idle due checks invoke no model

### Requirement: Current command admission does not expand historical scope
New personal exact-tool-proof runs SHALL use existing current-request command and
receipt checks for mission creation/control. Existing Calendar-only/text runs SHALL
retain their original command scope, including after retry or later proof changes.

#### Scenario: Old or corrupted personal command envelope
- **WHEN** a retained run lacks new command admission or its source was corrupted
- **THEN** it cannot record/apply a mission command or gain background authority

### Requirement: Original bounded receipt and withdrawal lifecycle
Every actual model call SHALL acquire the existing durable allowance/usage step
before IO. Original deadline/account/provider/connected-read/restore fences SHALL
remain in force. Started/unknown work SHALL NOT automatically reenter on restart.
Mail/Calendar writes, browser/vault/media and Claude background SHALL remain absent.

#### Scenario: Logout, cancellation and unknown dispatch
- **WHEN** a durable original owner logs out normally
- **THEN** only that original durable delegation remains eligible
- **WHEN** its original session-only authority ends or grant/connection is withdrawn
- **THEN** no new model/tool entry is authorized
- **WHEN** a dispatched call is interrupted or its result is unknown
- **THEN** only its original usage/evidence is retained and no retry inference occurs

### Requirement: Unambiguous singular English interval quotes
The existing civil validator SHALL accept exact every-minute/hour interval quotes
only for60/3600 seconds, preserve the original quoted unit and retain the minimum
60-second interval. It SHALL NOT infer an ambiguous time or relative delay.

#### Scenario: Every minute remains one minute
- **WHEN** the original current owner asks to repeat every minute
- **THEN** the interval proposal may be60 seconds and the same explicit delegation
  is saved and executed through the existing recurring mission contract
- **AND** a mismatched duration or relative-delay proposal is rejected
