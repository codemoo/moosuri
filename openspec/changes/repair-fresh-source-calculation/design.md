# Design

Use the existing learned evidence executor for fresh work. Store assigns search
ordinal0/read ordinal1, rechecks complete current source identity and field, then
records each checked arithmetic child. The wrapper accepts only current task
selectors and a typed arithmetic graph. Parameter, source-selection and field
failures expose bounded error categories. Same-slot replay returns the committed
result; reserve and actual cost remain inside12tool/6model/120second bounds.

Identical selector repetitions carry the same value. Record the first exact UTF8
span and retain disjoint ranges; complete numeric scalars still require exactly
one token. Search results and source field occurrences remain strictly unique.

Old profiles default the additive capability false. Existing explicit receipts
remain valid. Qualification accepts the exact old trace or one fresh composite
slot only, independently resolving actual children and checking arithmetic and
output adoption. A learned replay cannot become a new independent proof.
