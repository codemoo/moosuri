# Repair fresh source calculation

## Why
Natural requests repeat source names in output titles. Raw substring uniqueness
and manual pairing of query/search/read receipts caused recoverable calculations
to exhaust the six-call limit. F26/P4 needs actual fresh evidence and learned reuse.

## What Changes
- Add one typed fresh search/read/calculation operation backed by existing actual child receipts.
- Allow identical current query/prefix repetitions while preserving complete scalar, source and field uniqueness.
- Qualify the same structural private recipe from verified fresh children and owner-adopted reports/drafts.
- Preserve old persisted profiles, receipt vocabulary, budgets and all write/approval boundaries.

## Impact
Core tool profile, Store evidence/proof verification, Runtime tool schema, evidence documentation and outcome tests. No schema migration, external write or model downgrade.
