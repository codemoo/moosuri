# Discovery and execution remain separate

A shared base profile serves fresh chat and mission admission. Only fresh chat
adds original-request native discovery; mission admission retains its existing
separate grant path. Native mail shares the actual execution mail-domain gate.
Google terminal tools share their existing literal command predicates. A slash
is a conservative repository candidate bound, including canonical URLs and
Korean suffixes; it is not an authorization parser. No connected/unlocked grant
is required to discover the supported connection wait.

Runner and Store still reject live guidance for native stages. Later instructions
cannot add native tools, jobs or credentials. Retry/resume use the stored profile.
Old profiles, active mail/browser paths and native stages are not upgraded.
