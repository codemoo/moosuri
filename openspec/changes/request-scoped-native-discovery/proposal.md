# Request-scoped native discovery

## Why

A broker-enabled build exposed every native tool in every foreground request and
therefore disabled live instructions for otherwise ordinary read continuations.

## What Changes

Freeze native discovery from the original fresh-chat request using existing mail
and Google predicates plus a conservative repository candidate bound. Keep native
wait, execution authority, instruction exclusion and frozen resume profiles.

## Impact

Store foreground admission and synthetic Runtime/Store coverage. No migration,
new external operation or production deployment.
