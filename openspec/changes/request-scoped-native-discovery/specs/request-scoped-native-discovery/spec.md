## ADDED Requirements

### Requirement: Request-scoped native discovery
Fresh foreground chat SHALL freeze native discovery from its original request
without granting execution authority or disabling ordinary live guidance merely
because the broker feature is compiled in.

#### Scenario: Ordinary continuation in a broker-enabled build
- **WHEN** an ordinary final or local calculation stream is held open
- **THEN** it accepts guidance on the same run and excludes native tool schemas.

#### Scenario: Requested native route without a ready device
- **WHEN** the original request qualifies for native mail or terminal credential discovery
- **THEN** that route remains discoverable and outside live guidance, while existing execution and device checks remain required.

#### Scenario: Later guidance asks for native access
- **WHEN** an ordinary guidance-enabled run receives a new native request and a model proposes that tool
- **THEN** it creates no native job, read or commitment and does not enlarge the original profile.

#### Scenario: Existing retry or resume
- **WHEN** an admitted run retries or resumes
- **THEN** its stored tool profile remains unchanged by the new discovery policy.
