# Require successful mission response completion

F27 bounded missions can currently accept syntactically valid candidate or
clarification JSON even when the provider marks the response incomplete or
refused. A limit-truncated final proposal can therefore be reported as achieved,
or become an owner question. Require successful terminal semantics before
persisting an executable mission round. Keep completed earlier tool receipts and
observed usage, original budgets, and conservative restart behavior.

Also avoid an isolated task-classifier call for clear Korean answer/explanation
continuations. Existing selected tasks, clarification lineage, named controls,
and other explicit delegation/date cues retain their existing admission rules.
This cost routing does not authorize operations or certify semantic quality.
