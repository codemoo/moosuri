# Design

The admitted creation profile retains only qualified local source/arithmetic/workflow/evidence pins and matching metadata. Old saved profiles receive no new pins. Direct source-bound calculation stays foreground-only; its proven learned route re-reads the current source with quotes resolved from the accepted task and constraints.

One-off and recurring execution keeps the same server verifier, call budget, idempotent tool slot and source withdrawal. Arithmetic graph/source-calculation outputs expose exact result receipts. Changes-only comparison retains actual arithmetic/source identity and excludes run-local receipt addresses.

Actual read or learned execution records a recurring pin dependency. Disable/remove invalidates used/pending runs and reconciles dependent schedules. Mere discovery does not stop unrelated schedules. Restoring the exact qualified route still requires explicit schedule resume. Missions remain consumers and cannot produce self-training proofs. No parcel lookup, browser, credential, write or semantic-success authority is added.
