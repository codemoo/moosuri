# Immutable criteria with an execution floor

Schema52 adds a tenant/mission foreign-key sidecar of bounded immutable acceptance snapshots. Initial missions keep their original payload; the first edit records revision1 plus the new criteria. Each revision pins the first new model step. Original provider, account/session mode, admitted tools and connected scopes remain unchanged. At most eight edits are allowed.

The owner supplies task, constraints and typed checks with a UUID and current mission revision. Only stable paused one-off missions accept changes. Existing connected pins must remain current; new connected domains, unsupported effects/browser/vault/shell and unavailable explicit public web reads are rejected. Language screening is conservative, not a universal semantic classifier; typed execution capabilities remain the hard boundary. A save clears the active plan/candidate/round/additive steering and queues a fresh plan. Old criteria remain available in owner history. Model proposals cannot revise criteria.

Model/tool counters, original expiry, elapsed deadline, accounting receipts, repair count and knowledge dependencies remain untouched. Old leases are removed, including at saturated attempt32. Context, pending-slot admission, receipt projection, recoverable step leases and final recovery use the revision step floor; planned but unentered old tools are retained for audit and cannot execute or block re-planning. Plans/acknowledged rounds/verification carry the active acceptance revision. Legacy verification callers remain revision1-only. Source withdrawal, deletion, account epochs and restore retain existing fences.

Normal startup and offline sealed restore apply51 and52. The latter also repairs the preexisting missing51 forward hook. Physical account purging discovers tenant tables; explicit mission deletion clears the sidecar. Historical downgrade fixtures drop the new table before replaying migration SQL. UI editing is explicit authorization and preserves drafts/uncertain UUIDs without a second approval screen.
