# Stopped supported multi-version schema updates

P10's local pinned bundle update currently accepts only the installer's exact Store schema. Add a bounded immediately preceding schema → current migration flow using the signed target executable, original stopped writer lock and the real product Store migration. Preserve same-schema behavior, source exports and existing files. Official release distribution, arm64 acceptance and production migration remain separate gates.


The bounded extension fixes the supported source floor at47 and permits every
explicit Store migration through the target build's current schema. It replaces
current-1 admission without relaxing signed-source/target pins, stopped locks,
pre-update encryption or forward-only interruption recovery. Actual47→49 (and
later integrated current50) is the required real-binary acceptance; older source
schemas are not advertised from the presence of migration SQL alone.
