# Task-linked read-only source follow-up

After an achieved one-off task with actual saved-source receipts, offer a concrete follow-up scope. One explicit read/check/notify approval starts an expiring monitor; optional exact-scope/template reuse coalesces later matching tasks onto one schedule. A trusted connected-thread scope includes later synchronized replies in that same thread; exact-source fallback discloses that new replies cannot be detected.

Reuse the existing local reminder and recurring-mission machinery. Relevant material changes gate before child/model admission, with bounded changed-only reads, durable observation deduplication, and permission checks at dispatch and publication. Source-version-only changes and unrelated/unchanged evidence consume no inference. Coverage limits and removals remain explicit review states.

This adds no provider polling, wider search, external writes, mail-send permission, or global learned memory. Acknowledgements and corrections remain monitor-local.
